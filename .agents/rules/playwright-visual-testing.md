# Визуальное Тестирование и Скриншот-Аудит

Сквозная проверка интерфейса на сползание верстки (Layout Shifting) и визуальные дефекты.

---

## 1. Концепция
Зеленый статус тестов не гарантирует корректность отображения. Любые изменения в верстке, компоновке панелей или стилях карточек проверяются связкой **Playwright Screenshot + агентский инструмент `read_image`**.

---

## 2. Команды и создание скриншотов

```bash
npx playwright test
```

В коде теста:
```typescript
// Скриншот страницы
await page.screenshot({ path: 'test-results/screenshots/full-feed.png', fullPage: true });

// Скриншот компонента / карточки
await page.locator('#item-demo_task_1').screenshot({ path: 'test-results/screenshots/task-card.png' });

// Скриншот модального окна
await page.locator('.fixed.z-50').screenshot({ path: 'test-results/screenshots/modal-overlay.png' });
```

---

## 3. Аудит скриншота через `read_image`

Вызов инструмента:
```text
read_image({ file_path: "test-results/screenshots/full-feed.png" })
```

Чек-лист проверки:
1. **Сползание и переполнение**: Нет нежелательного горизонтального скролла. Элементы строки выровнены по базовой линии. Боковые панели не сжимают центральную ленту уже допустимого минимума.
2. **Текст и наложения**: Текст не залезает на кнопки и иконки. Длинные строки уходят в многоточие (`truncate`). Иконки защищены от сжатия (`shrink-0`).
3. **Контракт Linear Dark**: Нет рамок фокуса (`ring-0`, `outline-none`). Нет чипсов на чипсе (тип записи — чистый монотекст). Нет изогнутых скобок `border-l` + `rounded`. Монохромная палитра без кислотных градиентов.
4. **Модальные окна**: Окно отцентровано, подложка равномерно затемняет фон (`backdrop-blur-xl bg-black/80`).

---

## 4. Устранение дефектов
1. Зафиксировать найденное несоответствие.
2. Найти CSS-класс или разметку в TSX.
3. Исправить разметку (`shrink-0`, `min-w-0`, `gap`, `truncate`).
4. Перезапустить тест Playwright, сформировать новый скриншот.
5. Повторно вызвать `read_image` и убедиться в устранении дефекта.
