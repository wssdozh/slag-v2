# Визуальное Тестирование и Скриншот-Верификация

Сквозная проверка интерфейса и логики пользовательских действий через Playwright + скриншоты.

---

## 1. Концепция
Зеленый статус тестов не доказывает, что результат выглядит и работает правильно. Для правок в `src/components/**` и `src/*.css`:
1. Запустить тест, имитирующий пользовательский сценарий.
2. Сохранить скриншот итогового состояния в `test-results/screenshots/`.
3. Проверить через `read_image` на отсутствие дефектов.
4. **Обязательно показать скриншот пользователю в ответе**: `![Результат](<test-results/screenshots/<name>.png>)`.

---

## 2. Команды и создание скриншотов

```bash
npx playwright test
```

В коде теста:
```typescript
// Скриншот страницы после действия
await page.screenshot({ path: 'test-results/screenshots/action-result.png', fullPage: true });

// Скриншот измененного компонента / карточки
await page.locator('#item-demo_task_1').screenshot({ path: 'test-results/screenshots/task-card.png' });

// Скриншот модального окна
await page.locator('.fixed.z-50').screenshot({ path: 'test-results/screenshots/modal-overlay.png' });
```

---

## 3. Чек-лист проверки (`read_image`) и демонстрация пользователю
1. **Логика и состояние**: Действие выполнено, результат отобразился на экране (элемент создан, статус переключен, счетчик обновился).
2. **Верстка**: Нет лишнего скролла, строки выровнены, боковые панели не пережимают ленту.
3. **Текст и элементы**: Нет наложений текста, длинные строки обрезаны (`truncate`), иконки с `shrink-0`.
4. **Контракт Linear Dark**: Нет рамок фокуса (`ring-0`), нет чипсов на чипсе, нет изогнутых скобок `border-l` + `rounded`.
5. **Вывод пользователю**: Вставить картинку прямо в финальный ответ: `![Описание](<test-results/screenshots/<name>.png>)`.

---

## 4. Устранение дефектов
1. Зафиксировать найденное несоответствие.
2. Исправить разметку или логику в коде.
3. Перезапустить тест Playwright, обновить скриншот.
4. Проверить через `read_image`, убедиться в исправлении и прикрепить скриншот в ответ пользователю.

---

## 5. Мобильная верификация на устройстве (Android via ADB)
При проверке мобильной верстки или нативного поведения на реальном устройстве:
1. Деплой: `npm run build:android && npm run android:install && npm run android:run`.
2. Снятие скриншота: `adb exec-out screencap -p > test-results/screenshots/android_<name>.png`.
3. Проверка через `read_image` и демонстрация в ответе: `![Результат на Android](<test-results/screenshots/android_<name>.png>)`.
4. Чтение логов: `npm run android:log`.
