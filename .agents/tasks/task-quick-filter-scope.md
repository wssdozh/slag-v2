# Область быстрых фильтров задач

- **цель**: быстрый фильтр сужает набор записей текущего вида, не подменяя его область.
- **трогаем**: область в ленте, канбане и календаре; регрессия для «Входящие → Без даты».
- **не трогаем**: форматы, сроки, данные, синк и публикацию.
- **готово когда**: из общего вида доступны задачи в других папках, а внутри папки область не расширяется.
- **уже выяснили**: быстрый фильтр ошибочно заменял весь общий список на записи физической папки «Входящие».
- **перенос в `feat/note-replica`**: исходный коммит опирается на `master`; здесь карта кода сгенерирована заново, а правки расчёта дат из `master` не включены.
