# Рабочая синхронизация и отчёт хранилища

- **Цель:** реальная доставка Windows → Linux → Windows после установки, независимые правки не блокируются разбором, диагностика отделяет остановку доставки и неизвестную очередь от ожидающих решений.
- **Трогаем:** восстановительная процедура в `lib/sync`, диагностика и UI, безопасное разрешение выбранных полей, тесты и карта. Пять worktree от `686bbd8d`, интегратор сводит контракты и релиз.
- **Не трогаем:** старую очередь/маркер Windows (исходное хранилище остаётся архивом), пользовательский выбор даты, релейный протокол, Android/Pi. Поломки только на копиях. Не подставляем пустую очередь вместо неизвестной.
- **Готово когда:** синтетические сбои не теряют подтверждённое состояние; подписанная сборка на обоих клиентах доставила отдельную тестовую задачу в обе стороны с проверкой дисковой ревизии, значений и рестарта. В состоянии диска, доставки, очередей, старых правок и конфликтов отдельные строки. Выбор отдельных полей сохраняет независимые серверные изменения. Сравнить замеры задержки до/после.
- **Уже выяснили:** Windows сломан старый `state.json`, отдельный реестр cursor 261 и одна ожидающая операция читаются. Помимо неё штатный резерв в настройках содержит две старые папочные операции — известные кандидаты, а не доказательство полноты очереди. Linux: стабильный реестр #261, две пустые очереди, один старый снимок срока и ноль доказанных конфликтов. `syncHealth` ошибочно считает любой элемент разбора транспортной ошибкой. Комната сейчас использует реестр заметок, дерева и медиа без реестра общих записей.

Точка перехода для Windows: новая копия той же комнаты, хранилище секретов проверяет прежний ключ, доступ и поколение сравниваются до записи. Включается реестр; повреждённый старый пакетный канал не воспроизводится. Совпавшее с текущим релеем неопределённое отличие не становится операцией; отличающееся сохраняется в старой копии/на разбор. Не переносить опубликованные метки из старых бэкапов как новые квитанции. При любом непроверенном условии исходная копия остаётся рабочей локально.
