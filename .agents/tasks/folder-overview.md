# компактный обзор папки

- **цель**: поднять галерею в правой панели без отдельного заголовка.
- **трогаем**: статистику, вкладки и шапку правой панели.
- **не трогаем**: раскладку модалки и мобильного экрана, данные и синхронизацию.
- **готово когда**: в правой панели три счётчика записей в строку, числа вложений показаны только во вкладках, пустое описание доступно через меню.
- **уже выяснили**: панель и модалка используют общий профиль; разделяем внешний вид по существующему варианту.

- **итог**: сохранили теги доступными во вкладках; по первому скриншоту уменьшили горизонтальные отступы, чтобы крайняя вкладка помещалась в узкой панели. тестовые данные для снятой папки не содержат фото.
