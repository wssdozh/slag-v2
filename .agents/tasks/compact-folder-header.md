# Упростить шапку папок

- **цель**: убрать подписи шапки на мобильном, счётчик возле разбора на обоих экранах, точку на кнопке фильтров и число рядом с названием папки на десктопе.
- **трогаем**: мобильную шапку папок, шапку ленты и сценарии Playwright.
- **не трогаем**: навигацию, настройки фильтрации и условия доступности разбора.
- **готово когда**: стрелка возвращает к папкам, кнопка разбора без числа, кнопка меню без точки при активном фильтре.
- **уже выяснили**: отдельная точка у кнопки меню была только в десктопной шапке.

Проверено в отдельной копии с этими изменениями: `npm run check`, `npm run build` и 5 целевых тестов Playwright. В рабочей копии сборка прерывалась на параллельных правках компонентов папок.
