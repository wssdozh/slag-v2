# строка метаданных таски: один компонент на композер и редактор

- **цель**: срок, длительность, повтор и приоритет выглядят и ведут себя одинаково в композере и
  полноэкранном редакторе; дубль (`ComposerTaskControls` + `EditorTaskFields`) удалён.
- **трогали**: `src/components/UI/TaskMetaBar.tsx` (новый), `Feed/Composer.tsx`,
  `Editor/FullscreenEditor.tsx`, оба старых файла удалены, `e2e/slag/editor.spec.ts`,
  `e2e/slag/views.spec.ts`, `docs/CODE_MAP.md`.
- **не трогали**: `RecurrenceRule`, фронтматтер, парсер todoist, `DatePickerPopover`, `MenuDropdown`,
  `Select`.
- **готово когда**: в обеих оболочках контролы в одну строку, ПКМ сбрасывает, меню — `MenuDropdown`,
  статус есть только в редакторе, `npm run check` 0/0, `npm run build` зелёный, e2e по композеру и
  редактору проходят.

решения:

- эталон — композерный язык: `ToolbarButton` с иконкой, значение в `title`, сброс ПКМ, меню через
  `MenuDropdown`. Пилюли с текстом и кнопкой `×` из редактора убраны.
- внешнюю раскладку задаёт потребитель: компонент возвращает фрагмент. В редакторе это
  `flex flex-wrap items-center gap-1`, в композере — его собственный `contents md:flex …`.
- `size`: композер `md`, редактор `sm` — единственное законное различие оболочек.
- `dueTime`/`onDueTimeChange` — только у редактора; время без даты подставляет сегодняшнюю
  (`getTodayIso`), снятие времени снимает `reminder`.

что оказалось не так:

- первый заход поставил дату пилюлей с `×`, а длительность и повтор — иконками: получился гибрид, а
  не единый вид. Переделано на иконки у всех трёх.
- фрагмент без обёртки в редакторе лёг в родительский `flex-col` — контролы встали в столбик. Обёртка
  добавлена на месте, компонент по-прежнему её не навязывает.

осталось (не в этой задаче):

- длительность жёстко 15/30/45/60/90/120 — произвольного числа минут нет;
- пресеты повтора все с `interval: 1` — «каждые 2 недели» руками не задать;
- в композере `reminder` объявлен без сеттера, поэтому времени напоминания там нет.
