# Merge responsiveness into note replica

- **Цель**: объединить историю `perf/app-responsiveness` с `feat/note-replica`.
- **Трогаем**: только разрешение конфликтов в контексте, мобильных папках, их проверках и документации.
- **Не трогаем**: пользовательский незакоммиченный патч, удалённые ветки, staging APK, Rust-прототип и нативный стенд.
- **Готово когда**: проверены обе родительские линии Git, локальные проверки, root-за-Inbox, pull-to-search и сохранность пользовательского патча.
- **Уже выяснили**: ветки разошлись, Git нашёл пять конфликтов. Корень папок теперь живёт в `MobileFolderRoot`, поэтому перенесли туда жест, не меняя экран открытой папки. Тесты корня и мобильных настроек идут через «Назад к папкам» из «Входящих».

Проверено перед слиянием: `npm run check` (0 предупреждений), `npm run build`, 295 скриптовых и 91 целевой Playwright-тест, smoke на временном loopback-релее. Целевая ветка к моменту слияния была чистой; stash не использован. Полная браузерная матрица и нативный p95 не проверялись.
