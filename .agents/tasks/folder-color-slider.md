# Слайдер цвета папки и нижний угол карточки

- **цель**: горизонтальная цветовая шкала с бегунком вместо ряда кружков; действия карточки справа внизу.
- **трогаем**: пикер иконки, стили шкалы, расположение действий, целевые тесты.
- **не трогаем**: существующую палитру и формат хранения цвета.
- **готово когда**: бегунок перетаскивается и работает с клавиатуры, цвет сохраняется, действия не меняют размеры карточки.
- **уже выяснили**: десктопные действия уже внизу, мобильная кнопка статьи оставалась сверху.

Проверка кода, сборка и два целевых теста Chromium прошли. Нативное сенсорное устройство не проверяли.
