# Самовосстановление после повреждения состояния хранилища

- **цель**: при повреждении служебного JSON существующие Markdown-заметки открываются автоматически в локальном режиме чтения, с ясным предупреждением и остановленным синком. Критичная запись должна переживать потерю процесса/питания настолько, насколько это гарантирует ОС и устройство.
- **трогаем**: запись AppData и MCP; загрузчик vault; состояние/интерфейс восстановления; изолированные тесты.
- **не трогаем**: рабочий профиль, установленный SLAG, прод-релей, текущую ветку пользователя. Не сбрасываем и не заменяем старой копией журнал; не выпускаем релиз.
- **готово когда**: изолированный стенд с NUL вместо state.json показывает локальные заметки и явную ошибку, запись/синк не проходят; здоровый профиль без регрессии; тесты проверяют совместимость и отказ записи.
- **уже выяснили**: dev.74 из 1c29602c прерывает скан перед чтением Markdown при строгой проверке pendingFolderProjection. В пользовательском инциденте 106 читаемых файлов, state.json целиком NUL; системный сбой Windows коррелирует по времени. Write-then-rename не сбрасывает содержимое временного файла.

Три сабагента параллельно исследовали надёжную запись, локальную проекцию и тесты. После ревью интеграция не взяла непроверенные коммиты: переиспользован существующий сканер, тесты открывают реальный React с синтетическим IPC, запись реализована с Windows write-through и ограничением путей. Ошибочно внесённый worker-коммит удалён из исходной ветки без изменений пользовательского файла.

Успешно: `npm run check`, `npm run build`, `npm run test:scripts` (290 тестов); Playwright 13 прошли, один ранее отключённый; Rust Windows-тест заменяет файл и моделирует отказ до публикации. Тест с 43 763 нулевыми байтами показывает 106 заметок без записи или обращения к релею. Ретрай не считает исчезновение повреждённого файла восстановлением. Не проверялись обесточивание в VM и физические Linux/Android-устройства. Старый журнал не восстанавливается из непроверенного снимка; рабочий main не чинится этим изменением автоматически.
