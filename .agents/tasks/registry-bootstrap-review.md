# Разбор локальной корзины при первом запуске реестра

- **Цель**: дать оператору явно оставить проверенные записи только в локальном архиве, не выдавая отсутствие живой копии за удаление, и сохранить отличающуюся живую копию по подтверждённому восстановлению.
- **Трогаем**: планировщик seed, локальный CLI, тесты и инструкцию миграции.
- **Не трогаем**: рабочую комнату, исходные снимки и записи; не отключаем проверки устройств, очереди, медиа и неоднозначных живых копий.
- **Готово когда**: проверены планировщик и изолированный `freeze → activate`, ни одна archive-only запись не превращается в удаление на релее.
- **Уже выяснили**: на трёх предварительных снимках есть старая корзина без записей в ограниченном legacy-журнале; снимки сохраняют отдельные физические копии.

Это изменение только в локальном планировщике. `archive` не допускается для живых записей и не создаёт tombstone. Для новой редакции той же заметки журнал может подтверждать либо восстановление, либо последующее удаление; оба решения требуют проверенного происхождения. Две различные живые копии нельзя согласовать этим листом. После активации запись из старой корзины без tombstone можно вернуть отдельным импортом как новую запись.
