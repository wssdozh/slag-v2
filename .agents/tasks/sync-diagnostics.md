# диагностика расхождений синка

- **цель**: по логу видно, с чьей сводкой разошлись и что произошло с явным удалением.
- **трогаем**: сверка сводок, приём пакета, фиксация импорта и тесты сверки.
- **не трогаем**: протокол, решение о записи/удалении, рабочую комнату и интерфейс.
- **готово когда**: тесты сверки и удаления зелёные; `npm run check` и `npm run build` проходят.
- **уже выяснили**: сообщение о разных копиях не показывает, какой сосед, каких записей не хватает и насколько стара его сводка. устаревшая анонимная сводка не запускает реакцию.
