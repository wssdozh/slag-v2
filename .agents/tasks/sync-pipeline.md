# Пайплайн синка: манифест на устройство, быстрая сверка, реакция

## Цель

Правка уходит наружу сразу, сверка видит **чужие** корни через доли секунды после отправки, и по
итогу: тишина / одна переотправка / адресный запрос / корзина / `CloudAlert`.

## Что сделано (три параллельные ветки)

- **релей** (`feat/relay-manifest-per-device`, `c6871da` + `ac3183a`): таблица
  `room_device_manifests` с ключом `(room_id, device_id)`, `GET ?device=` отдаёт чужие корни,
  легаси-строка возвращается как `anonymous`, `at` — время записи строки в мс. Старая таблица и
  старый формат нетронуты: телефон на dev.29 продолжает писать туда.
- **клиент** (`feat/sync-pipeline`, `00cbb14` + `28f8bcb`): папка `src/lib/sync/manifest/`
  (`channel`, `peers`, `publish`, `schedule`, `resolve`, `prefs`, `sync`), решение по массиву
  пиров, сверка 800 мс после подтверждения, повтор 1.5 с, heartbeat 30 с, адресный `note_request`.
- **чистка** (`chore/cleanup-perf-map`, `a569af0`): ленивый CodeMirror (редактор вне стартового
  замыкания), перегенерённая карта, строка карты в `AGENTS.md`.

## Критерий готовности

`npm run check` 0/0, `npm run build`, синк-спеки зелёные, на живой паре машин расхождение
сходится без ручных действий, `Убрал в корзину` появляется только когда сосед переопубликовал
корень.

## Что оказалось не так, как думали

- **Главная причина была не в таймингах.** Дебаунс пуша и так 50 мс. Слепой была сверка: одна
  строка на комнату → сравнение с собой. 86 «корень сходится» за день при 90 и 89 заметках.
- **Авторазбор едва не стал опасным.** Сосед применяет бандл сразу, а свой манифест
  переопубликует позже (до heartbeat). Без `at` это выглядит как «отказался», и корзина съела бы
  только что принятые заметки. Гейт `peer.at > manifestResentAt` обязателен, и он же делает
  авторазбор безвредным на старом релее (там `at` нет → не разбираем).
- **`anonymous`-пир нельзя переотправлять.** Легаси-строка замирает: корень там больше не
  обновится. Ресэнд в неё — бандлы в пустоту, а красная панель — вечно. Поэтому по анониму
  только «нет данных о соседе» серым, без действия.
- **Мёртвых экспортов не нашлось.** 612 модулей, все используются; `ponytail-audit` дал пусто, и
  это честный результат, а не пропуск. Реальная экономия старта — ленивый CodeMirror, не удаление.
- `leavesToRequest` годами лежала без вызовов — теперь это и есть адресный запрос недостающих.
