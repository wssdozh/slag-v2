# Непрерывная шкала цвета папки

- **Цель:** градиент оттенков и закруглённый бегунок-полоска без обводки.
- **Трогаем:** шкалу, отображение цветов папки, валидацию и тест выбора.
- **Не трогаем:** позиционирование меню и остальные элементы интерфейса.
- **Готово когда:** промежуточный оттенок отображается при перетаскивании, передаётся в существующее сохранение папок; старые оттенки не меняются.
- В браузерном демо обычные метаданные папок живут в памяти до перезагрузки. Playwright проверяет повторное открытие пикера и отображение в другой панели; основной путь загрузки и синхронизации принимает новый формат через общий валидатор.
