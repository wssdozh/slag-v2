# Чтение заметок и навигация

- **цель**: выделять текст и открывать ссылки из ленты; сворачивать цитаты и скрывать спойлеры от тегирования; менять иконку и цвет папки из навигации; компактный профиль.
- **трогаем**: карточку и Markdown, меню форматирования, AI тегирование, метаданные папок, сайдбар, профиль и существующие спеки.
- **не трогаем**: формат хранения тела Markdown, AI чат, новые экраны «Сегодня / Потом», сетевой API.
- **готово когда**: один финальный `npm run check`, `npm run build`, Playwright и скриншоты; тестовый секрет не попадает в запросы тегирования.
- **уже выяснили**: draggable на карточке мешает выделению; Tauri уже имеет opener; пакетный триаж отправляет заголовок и теги отдельно; диск читает FolderMeta по явному списку полей.

## Итог

- В карточке текст выделяется и копируется; область перетаскивания отдельная. В вебе ссылки открывает браузер, в Tauri используется существующий opener.
- Спойлеры исключаются из текста одиночного тегирования и триажа. Свёрнутые цитаты остаются доступными ИИ.
- Цвет и иконка меняются из навигации и профиля папки. На мобильном профиль помещается в одну строку: аватар, имя и статус, действие аккаунта.
- `npm run check` и `npm run build` прошли. Целевые сценарии Playwright прошли на повторных прогонах; холодный Vite давал таймауты. Веб-спека подтверждает отображение цвета в двух местах, не сохранение на нативном диске после перезапуска. Сборку Tauri не запускали.
- «Сегодня / Потом» остаётся для обсуждения.
