# аналитика занятого места в настройках

- **цель**: в разделе «Хранилище & Бэкап» — секция «Занято места»: итог usage/quota, разбивка localStorage по группам, медиа по типам, снимки, память ассистента, топ-12 самых тяжёлых файлов с переходом в заметку.
- **трогаем**: новый `src/lib/storage/usage.ts`, новый `src/components/Settings/StorageUsageSection.tsx`, вставка секции в `src/components/Settings/VaultSettingsTab.tsx`.
- **не трогаем**: вкладку ИИ и `MemoryList`, backup-логику, `src-tauri/`, синк, `package.json`, e2e (его гоняет родитель). байты из IndexedDB не читаем — только метаданные.
- **готово когда**: `npm run check` чист; в секции видны итог, группы, медиа, снимки, память и топ-файлы; сумма групп равна общему объёму localStorage; пустое хранилище даёт нули без `NaN`.
- **уже выяснили**: `SlagAttachment.size` и `BackupSnapshotMeta.sizeBytes` уже есть в метаданных; подсчёт байт localStorage по ключам есть в `logger.getStorageHealth()`; `formatBytes` и `SettingsGroup`/`SettingsRow` переиспользуются; `navigator.storage.estimate()` в проекте не используется и на старых WebView может отсутствовать; открыть заметку = `setSelectedItem` + `setIsFullscreenEditorOpen(true)`.

после работы допиши: что оказалось не так, как думали, и что осталось.

## что оказалось не так

- Квота в гигабайтах печаталась как «10240.0 MB»: у `formatBytes` не было шага GB. Добавлены две строки, точные ожидания в `ui_refactor.spec.ts` (B / KB / MB) не тронуты.
- `settings_consistency.spec.ts` требует `button button` = 0 на вкладке хранилища, поэтому «Обновить» живёт в `action` заголовка группы, а не внутри `SettingsRow`.
- «Занято» = `max(navigator.storage.estimate().usage, сумма строк)`: оценка платформы отстаёт и не видит байты desktop/FSA-хранилища, а сумма по метаданным — точная нижняя граница. Снимки в итог не входят: это копии, у них своя строка.
- Разложение ключей: `slag_attachments_*` — в «Заметки» (это индекс вложений, не байты), `slag_workspace_state_*` и точные ключи `STORAGE_KEYS` — в «Настройки», синк-обвязка, сессии и 2FA — в «Прочее».
- Настройки скроллят вкладку, поэтому весь раздел в один скриншот не влезает: в e2e два снимка — итог и тяжёлые файлы.
- Грабли: `Set-Content` в PowerShell перекодировал файл с кириллицей в мусор. Кириллицу править только инструментом `edit`/`write`, не консолью.
