# task-e2e: матричный спек пользовательских сценариев задач

**Цель:** один переиспользуемый контур и матричный спек, описывающий поведение задач (reminder, повтор, завершение, мобильный вид, сохранение данных). Не переписывать существующие спеки — проверить *поведение*, а не *реализацию*.

## Файлы

### e2e/support/taskFixtures.ts
Функции-хелперы: `seedTask`, `readStoredItem`, `openTaskEditor`, `waitForAutosave`, `setMobileViewport`. Сид через `page.evaluate` + `storage.saveItem` (без прямого localStorage).

### e2e/support/slagSetup.ts
Изменение: ожидание `main` поднять с 120 до 240 секунд, один повтор `page.goto` при таймауте. Больше ничего не менять.

### e2e/task_matrix.spec.ts
Матрица независимых тестов (каждый свой сид):
- s1 reminder: iso offset, перенос даты, снятие срока, переоткрытие, legacy `'10:00'`
- s2 повтор: daily, 2 недели пн+ср (fixme b05), yearly, resetSubtasks:false (fixme b06..b07)
- s3 завершение: последний пункт закрывает, переименование не закрывает
- s4 мобильный: 390x844, текстом срок/время/длительность/повтор, кнопка >= 44px
- s5 данные: старый reminder без зоны не теряется, MCP-контракт не трогаем
