# Убрать четыре воспроизведённых ошибки слияния

- **цель**: не терять шаги и привязки вложений, не открывать ручной разбор для уже достигнутого результата, не считать разные ISO-записи одного момента двумя одиночными напоминаниями.
- **трогаем**: слияние и валидацию заметок, выбор исхода в журнале, изолированные регрессии, карту синхронизации и матрицу отказов.
- **не трогаем**: рабочую комнату и профили, правила автообъединения разных деревьев, повторяющиеся напоминания, ручное разрешение старых аргументированных альтернатив, протокол релея.
- **готово когда**: до фикса регрессии падают по четырём причинам, после фикса полные альтернативы сохраняются при неоднозначности, совпавшие локальные намерения не отправляются и не застревают, тесты и сборка проходят.
- **уже выяснили**: [четыре исходные пробы](../../docs/sync-resilience-matrix.md#1-подтверждено-локальными-пробами); проверять обратный порядок сторон и позитивные контроли.

---

Четыре регрессии воспроизвели исходные ошибки до изменения кода. В случае конкурирующих чеклистов безопасное значение не угадываем: сохраняем полный локальный вариант, пока общий чеклист не выбран. Если одинаковые пункты уже перенесены в Markdown, отдельного разбора нет. Правка подписи не перепривязывается к иному ID; в ручном редакторе можно явно адресовать ID. Разные напоминания, повторы, жизненные переходы и групповые операции не объявляются автоматически равными. Ранее сохранённые обычные конфликты эта правка не удаляет.

Проверки: `npm run check`, `npm run build`, `npm run test:scripts` (337), 11 Playwright-сценариев интерфейса, оба режима настоящего loopback-релея. В расширенном офлайн-прогоне три одинаковые правки не создали лишней ревизии; чеклист и подпись создали две полные альтернативы, прочитанные заново через формат журнала. Финиш трёх реплик — `157`. Реальные профили и рабочая комната не затронуты.
