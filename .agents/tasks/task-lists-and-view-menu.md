# Быстрые фильтры задач и компактное меню «Вид»

- **Цель:** один клик сужает текущую контентную вкладку до задач нужной категории. Второй клик снимает фильтр. Панель, режим и папка не меняются.
- **Трогаем:** адресацию Dockview, сайдбар, общие правила срока/статуса, входы ленты/канбана/календаря, календарную панель «Сроки», тесты и карту кода.
- **Не трогаем:** форматы Markdown, синк, MCP, мобильную навигацию и данные задач. Компактное меню сохраняем; у групп вариантов фон только у выбранного пункта.
- **Готово когда:** все четыре фильтра работают в трёх режимах в рамках папки с подпапками; сегодня включает просрочку; календарь показывает задачи без даты в существующей панели. Другая вкладка не фильтруется, при смене вкладки/папки/хранилища фильтр не наследуется. Проверки: check, build, Playwright, скриншоты и локальный замер клика.
- **Выяснили:** исходный отдельный экран отклонён. Лента, канбан и календарь сохраняют собственные порядок и раскладку. Истинной даты завершения пока нет. В календаре есть переиспользуемая панель «Сроки».

- **Реализация:** один фильтр в состоянии рабочего пространства; Dockview при смене вкладки сообщает активную вкладку группы раньше, чем обновляет флаг видимости отдельной панели. Календарь переиспользует одну карточку для обоих разделов «Сроков» и после раскрытия панели доводит текущий день в видимую область недели.
- **Проверки:** `npm run check` — 0 предупреждений и ошибок; `npm run build` успешен. В Playwright прошли все 5 сценариев быстрых фильтров, компактное меню на десктопе и мобильном и переключатель выполненных. В расширенном прогоне — 18 из 20, два сценария профиля папки не дождались модального окна. Полный прогон остановлен после падений в сценариях памяти/ИИ и холодного таймаута; весь набор зелёным не подтверждён.
- **Замер:** медиана 36 мс (5 активаций «Сегодня» на 5 000 дополнительных записей в папке, Chromium, от вызова клика до обновления DOM; не сравнение с предыдущей версией).
- **Визуальная правка:** навигация, выбор периода и «Сроки» в десктопном календаре используют кнопки высотой 32 px без общей подложки. Меню вида открывается тремя точками на десктопе и мобильном, сброс оформлен штатной кнопкой.
