# синхронизация: одна кнопка обновления вместо двух

- **цель**: на вкладке «Синхронизация» ровно одна иконка-кнопка: она проверяет адрес релея и перепроверяет статус (пуш) за один клик; во время работы — спиннер, повторное нажатие заблокировано, ошибка приходит одним тостом. У строки «Смена ключа хранилища» остаётся заголовок и кнопка, без описания.
- **трогаем**: `src/components/Settings/SyncSettingsTab.tsx`, `e2e/sync_settings_flow.spec.ts`, `e2e/settings_consistency.spec.ts`, `e2e/device_actions_and_scroll.spec.ts` (там зашито имя прежней кнопки).
- **не трогаем**: `src/components/Modals/BaseModal.tsx` (параллельная ветка), `SettingsUI.tsx` (аддитивный проп не понадобился), подтверждающий диалог смены ключа — его текст уже объясняет последствия.
- **готово когда**: `npm run check` печатает `0 warnings and 0 errors`; `SLAG_E2E_PORT=6114 PLAYWRIGHT_WORKERS=1 npx playwright test e2e/sync_settings_flow.spec.ts e2e/settings_consistency.spec.ts e2e/device_actions_and_scroll.spec.ts` зелёный; скриншот `test-results/screenshots/sync-single-refresh.png`; один коммит.
- **уже выяснили**:
  - кнопка у статуса звала `syncEngine.pushLocalChanges()` и не трогала адрес; кнопка у адреса делала `/health` → `detectServer` → `updateServerUrl` → `startPolling` и показывала тост. объединение = один обработчик, проверка остаётся отдельной вызываемой функцией;
  - `updateServerUrl` рвёт сокет, чистит bookkeeping и заново инициализирует движок. если адрес не менялся, это лишняя пересборка — вызываем только при реальной смене;
  - `pushLocalChanges` не бросает: ошибки складывает в `status.error`, поэтому единственный бросающий шаг — проверка сервера, и тост про ошибку остаётся один;
  - в спеке настроек тост «Не удалось проверить сервер: HTTP 503» ищется по тексту, а кнопка — по accessible name `Проверить`. имя меняем на `Обновить`, спек переводим на `data-testid="sync-refresh-btn"`;
  - прежняя кнопка статуса называлась `Синхронизировать`; её имя зашито ещё в `device_actions_and_scroll.spec.ts`.

---

оказалось не так:
- кнопку хотели в шапку карточки, но там подпись `E2EE` на 10px, а `IconButton` в ней — `sm` (24px). на мобильном это промах по тапу, поэтому оставил кнопку на строке статуса: `lg` даёт 32px на десктопе и 44px в `max-sm`. шапка осталась с одним `E2EE`.
- `updateServerUrl` при проверке вызывался всегда, даже когда адрес не менялся, и каждый клик пересобирал движок (рвёт сокет, чистит synced ids/tombstones/курсор). теперь он идёт только на реальной смене адреса — проверка перестала быть разрушительной.
- `isTestingServer` переименован в `isRefreshing`: состояние описывает всю проверку (адрес + пуш), а не только `fetch('/health')`.
- имя старой кнопки `Синхронизировать` жило в двух спеках, а `Проверить` — в `settings_consistency`. обе переведены на `data-testid="sync-refresh-btn"`; заодно `settings_consistency` теперь держит `/health` за гейтом и проверяет `aria-busy`, `disabled`, класс спиннера и ровно один тост.
- `pushLocalChanges` не бросает — складывает ошибку в `status.error`, поэтому единственный источник тоста — проверка сервера; отдельный catch вокруг пуша не нужен.

осталось: монтажный `useEffect` всё ещё дергает `detectServer` на каждое изменение адреса (и на открытие вкладки), то есть один лишний `/health` без спиннера. это не кнопка и не тост — не трогал, чтобы не расширять задачу.
