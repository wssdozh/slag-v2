# точка доставки на карточке записи

- **цель**: текущая версия записи показывает локальное состояние, очередь, подтверждение релея, ошибку отправки или конфликт.
- **трогаем**: чтение статуса из существующих журналов, карточку ленты и тесты.
- **не трогаем**: протокол доставки, рабочую комнату и устройства.
- **готово когда**: новая правка не наследует зелёную точку; неподтверждённое остаётся в очереди; браузерный тест видит смену состояний.
- **уже выяснили**: legacy хранит хэши отправленных записей после ACK, реестр хранит подтверждённые значения. ни одно не доказывает применение другими устройствами или загрузку вложений.

проверено: браузерный сценарий создаёт заметку, видит локальную точку, очередь, ошибку http и принятие после ответа. новая версия не наследует квитанцию. тест реплики отдельно проверяет pending/accepted/error. ошибки показа живут в памяти; сами операции остаются в существующем журнале, новый журнал не нужен.

- Индикатор перенесён в строку времени, включая голосовые и файловые карточки. Критерий: не перекрывает время, остаётся один на запись. Не считаем наличие копий на устройствах подтверждением текущей версии.
