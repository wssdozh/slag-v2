# мобильная шапка и сводка синхронизации

- **цель**: облачко вместо логотипа, лёгкие табы, компактная сводка.
- **трогаем**: мобильные папки, настройки, список устройств и отображение синка.
- **не трогаем**: протокол и данные синхронизации.
- **готово когда**: check, build и мобильные скриншоты.
- **уже выяснили**: серый цвет не означает офлайн, сводка не является присутствием.

---

десктоп оставляет обычный обмен визуально тихим; смена облачка при обмене только на телефоне. сводка общая для обоих экранов. нативную сборку не выпускали.
