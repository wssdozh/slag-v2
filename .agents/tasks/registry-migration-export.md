# Локальный снимок для миграции реестра

- **Цель**: получить с Android проверяемый архив текущего рабочего хранилища: оригинальные Markdown, корзину, медиа и минимальный журнал синка.
- **Трогаем**: настройки переноса, экспорт только для Android, разрешения системного сохранения, тест.
- **Не трогаем**: рабочую комнату, локальные заметки, авторизацию, ключи и облачную передачу. Архив нельзя импортировать как бэкап.
- **Готово когда**: архив содержит ожидаемые данные и только нужные поля синка, тесты и сборка зелёные; сохранение подтверждено на изолированном Android.
- **Уже выяснили**: штатный ZIP не содержит удалённые записи и очередь; release `run-as` закрыт. Windows/Linux архивы сохранены и проверены.

Playwright с подменой нативного IPC проверил точные байты, журнал без конфигурации/ключей и отказ импорта. Локальный Vite зависал на холодном старте, поэтому сценарий собран отдельным in-memory bundle. Нативное сохранение подтверждено в подписанном [dev.65](https://github.com/wssdozh/slag-v2/releases/tag/v0.2.5-dev.65): обновление на месте, системный выбор локальной папки, скачивание через USB и совпадение SHA-256. Снимок успешно разбирается; он предварительный, не из замороженной комнаты. Рабочую комнату не переключали.
