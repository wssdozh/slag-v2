# Полевая матрица задач, заметок и статей

- **цель**: явный контракт для каждого поля доменной модели и проверка всех поддерживаемых изменений через общие границы записи, проекции и слияния.
- **трогаем**: матрицу и регрессии; исправляем только воспроизведённые дефекты.
- **не трогаем**: пользовательские данные, рабочий релей, выкладку, UI и сетевой формат без необходимости.
- **готово когда**: новое поле ломает тест покрытия до добавления случая; нормальные правки переживают диск и зашифрованную доставку, безопасные объединяются, конкурирующие остаются видимыми, а локальные поля не просачиваются в протокол. По каналам изменения есть ссылки на сценарии и границы покрытия.
- **уже выяснили**: SlagItem объявлен общим интерфейсом; правила допустимости зависят от `type`. Markdown, шифрованный журнал и индекс на устройстве имеют разные обязанности.

## Результат

- [Матрица полей и способов записи](../../docs/sync-item-field-matrix.md), [AST и полевые регрессии](../../scripts/note-field-matrix.test.mjs). Подтверждены и исправлены несогласованные значения по умолчанию, перенос полей прежнего типа, пропуск YAML с подтверждённой базой при закрытом приложении, стирание отдельного чеклиста при разборе и восстановление уже удалённых чекбоксов в ИИ/MCP. Фоновые метаданные одного принятого blob больше не сталкиваются с независимой формой волны.
- На тестовом релее при RTT 40 мс три клиента дошли до ревизии 174: очередь пережила перезапуск, три вида записей получили и независимые заголовки, и офлайн-очистку свойств. Новый разбор не появился; настоящие конфликты из предыдущих сценариев остались.
- Гипотеза о потере inline-тегов при круговом проходе не подтвердилась; позиционный ID Markdown-чекбокса не следует объявлять внешним постоянным ID. MCP отказывается писать в зарегистрированный vault; это проверенный контракт, а не незаметный обход синка.
- Остаётся: три уже падавших браузерных сценария, нативная проверка Windows/Linux/Android, внешние физические переносы/удаления и YAML без доказуемой базы. Рабочий релей и профили не трогали.
