# AGENTS.md — Кодекс SLAG v2

Стек: **React 19, TypeScript, Tailwind CSS v4, Tauri v2, Orama BM25, Playwright, Vite**.

---

## 1. Канонические правила

1. **Tauri-Free View (MVP)**: Запрещено импортировать `@tauri-apps/*` в компоненты (`src/components/`) и UI-хуки. UI — чистый View: только рендерит и вызывает экшены `AppContext` (Presenter). Все системные вызовы и работа с файлами — строго в `src/lib/storage.ts` (Model). Это обеспечивает работу в браузере и быстрые тесты без Rust-бинарника.
2. **Obsidian Local-First**: Заметки — чистые `.md` с YAML Frontmatter. Медиа — в `.attachments/`, удаление — в `.trash/`. Модели данных — в `src/types/index.ts`.
3. **No Crutches & Ponytail**: Запрещены `?.` для маскировки кривых данных, пустые `catch`, `setTimeout(..., 100)` и флаги состояния вроде `isPatchApplied`. Устранять первопричину в источнике данных (`storage.ts`, `AppContext.tsx`). Использовать лестницу простоты: YAGNI ➔ утилиты `src/lib/` ➔ нативный JS/TS/Web API ➔ установленный пакет ➔ 1 строка ➔ минимальный код. Осознанные компромиссы маркировать: `// ponytail: <лимит и путь решения>`.
4. **Контракт верстки Linear Dark (95% Fidelity)**:
   - Палитра: фон `#08090a`, панели `#0c0c0e`, карточки `#141417` (hover `#161619`), модалки `#121215/95`, границы `border-white/[0.05]` (hover `border-white/[0.12]`), текст `zinc-100` / `zinc-400` / `zinc-500`.
   - **Антиматрёшка**: запрещен «блок в блоке» — никаких карточек внутри карточек, вложенных рамок и внутренних подвалов. Контент живет на первом уровне, иерархия задается типографикой и отступами (`gap-2`).
   - **Без «чипсов на чипсе»**: тип записи (`Таска`, `Статья`) — чистый монотекст `text-[11px] font-mono text-zinc-400` без цветных фоновых плашек.
   - **Без изогнутых бордеров**: запрет `border-l-*` со скруглением `rounded-*`. Для реплаев и цитат — плоская типографика `↳` или прямой штрих `rounded-none`.
   - **Без рамок фокуса**: `outline-none ring-0` на всех инпутах и кнопках.
   - **LIFO-стек**: `Escape` или клик мимо закрывает строго верхний оверлей.
5. **Zero-Slop ИИ**: Без приветствий и вежливых подводок. Перед генерацией тегов сверять существующие теги хранилища (Taxonomy First, без дублей). Факты проверять через `search_notes` / `read_note` (Grounding). Создание заметок оформлять через карточку подтверждения в UI (`action: create_note`).
6. **Логирование**: Без сырых `console.log`. Использовать `logger.scope(...)` с замером времени и автоматическим маскированием API-ключей (`gsk_`, `AIzaSy`).

## 2. Пайплайн задачи и DoD

1. **Изучение**: Найти затронутые файлы через `glob` и `grep`. Не спрашивать пользователя о том, что уже есть в кодовой базе.
2. **Планирование**: При неопределенности >10% вызвать `ask_user_question`: 1 конкретный вопрос, 2–4 варианта с компромиссами, рекомендуемый первым с пометкой `(Рекомендуется)`.
3. **Реализация**: Минимальный diff без лишних абстракций. Работать автономно до полного завершения.
4. **Правило 3 попыток**: При повторении ошибки сборки или тестов 3 раза подряд — остановиться, привести лог и запросить решение через `ask_user_question`.
5. **Критерии готовности (DoD)**:
   - `npm run lint` — 0 warnings, 0 errors (`oxlint`).
   - `npm run build` — чистая сборка (`tsc -b && vite build`).
   - `npx playwright test` — 100% тестов пройдены.
   - Изменения UI: сделать скриншот в тесте (`test-results/screenshots/`), просмотреть через `read_image`, проверить на отсутствие сползания верстки, наложений и рамок.
   - Атомарный коммит Conventional Commits на английском языке.
