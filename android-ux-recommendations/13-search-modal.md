# 13а — файл с названием поиска, но без поиска на экране

[← оглавление](<README.md>)

[скриншот 13а](<../test-results/screenshots/audit/13_search_modal.png>)

**наблюдение.** виден корень папок, ни строки поиска, ни клавиатуры, ни модалки нет. имя файла не является доказательством открытого поиска. новых дефектов относительно 12 не видно.

**рекомендация — проверка, не подтверждённый баг.** проверить обратную связь кнопки поиска: один тап должен открывать поиск и фокусировать поле, не требуя второго точного попадания. не объяснять этот кадр «сломавшимся поиском» без записи действий.

**приёмка.** из корня папок один тап по центру и краям области поиска открывает одинаковое состояние; повторное быстрое нажатие не создаёт два оверлея. сохранить отдельные кадры до и после действия с отметками времени.
