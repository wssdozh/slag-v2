**рекомендация — пробел доказательств.** повторить проверку ориентации именно с активным приложением заметок, зафиксировав foreground activity, размеры viewport и новый снимок. текущий файл исключить из визуальных доказательств landscape; не менять ориентацию приложения на основании этого кадра.

**приёмка.** portrait → landscape → portrait в ленте, редакторе с черновиком, настройках и при IME: элементы доступны, реальные insets пересчитываются, текст/папка/выделение сохраняются. для публичной передачи отчёта этот посторонний снимок не включать без необходимости; здесь оставлена только ссылка для трассировки, не встроенное изображение.
