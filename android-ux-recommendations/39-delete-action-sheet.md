# 39 — удаление конкретной статьи

[← оглавление](<README.md>)

[скриншот 39](<../test-results/screenshots/audit/39_delete_action_sheet.png>)

**наблюдение.** шторка подписана `TestNoteAndroid`, выбран тип «статья», пункт удаления отделён от архива и выделен красным. это снижает риск удалить не ту запись. остальные замечания к содержимому меню — в 19.

**изменение — p1.** действие удаления переводит запись в корзину и даёт восстановление, не уничтожает файл безвозвратно. подтверждение отдельным диалогом необязательно для обратимого перемещения; если операция необратима, нужно явное подтверждение с названием записи. при ошибке не скрывать запись так, будто удаление прошло.

**приёмка.** удалить именно выбранный id, проверить исчезновение из ленты/поиска и доступность восстановления с телом, вложениями и метаданными. повторное нажатие не создаёт несколько конфликтующих операций; удаление офлайн доставляется после входа без самопроизвольного воскрешения от устаревшей копии. это сценарии проверки, не установленная по шторке ошибка sync.
