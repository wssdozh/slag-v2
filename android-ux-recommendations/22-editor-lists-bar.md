# 22 — меню списков и блоков

[← оглавление](<README.md>)

[скриншот 22](<../test-results/screenshots/audit/22_editor_lists_bar.png>)

**наблюдение.** вместо стилей открыто меню «списки и блоки», все шесть пунктов читаются, активна соответствующая кнопка. «ссылка [[заметка]]» раскрывает синтаксис, но не объясняет выбор целевой записи. нового визуального блокера нет.

**изменения — p2.** при переходе между инструментами заменять верхнее меню, а не складывать невидимые слои. «ссылка на заметку» должна позволять выбрать существующую запись, сохраняя диапазон вставки; пустую конструкцию `[[…]]` не считать завершённым действием. операции списков применять к текущему блоку/выделенным блокам, не ко всей заметке.

**приёмка.** быстро переключить стили → списки → стили: один back закрывает одно видимое меню. проверить создание чек-листа, выход из пустого пункта, нумерацию, многострочное выделение, отмену последней операции и сохранение после повторного открытия. существующая выполненная подзадача не теряет состояние при форматировании соседнего абзаца. по кадру эти действия ещё не проверены.
