# 28 — клавиатура скрыта, папка ещё не выбрана

[← оглавление](<README.md>)

[скриншот 28](<../test-results/screenshots/audit/28_folder_selected.png>)

**наблюдение.** `@` остался, меню папок открыто, текущая «карьера» выделена; клавиатура исчезла. выбор другой папки не подтверждён, несмотря на название файла. список переместился вместе с композером вниз и целиком помещается в кадре.

**рекомендация — p2.** сохранить достижимость вариантов после скрытия IME, но не считать потерю фокуса выбором первого пункта. предусмотреть явную отмену автокомплита без знания `Esc`: системный back/тап вне либо доступная кнопка закрытия. поведение back с IME и подсказкой определить однозначно; не закрывать обе одним событием случайно.

**приёмка.** скрыть IME, затем пальцем выбрать последнюю папку; применяется именно нажатая строка, не текущая. отмена не удаляет остальной черновик. повторное касание `@` позволяет продолжить фильтрацию; resize не публикует и не переносит запись.
