# 25 — выбран тип «статья», поле пока пустое

[← оглавление](<README.md>)

[скриншот 25](<../test-results/screenshots/audit/25_composer_input_active.png>)

**наблюдение.** меню закрыто, тип изменён на статью; placeholder стал «черновик статьи… (@ папка, # тег)». клавиатуры нет, активный ввод изображением не подтверждён. непустого пользовательского текста не видно.

**изменение — p2.** тип новой записи отображать явно, как здесь, но отделить его от состояния черновика: слово «черновик» в подсказке не подтверждает фактическое сохранение. для статьи предложить раскрытие полного редактора как вторичное действие, не заставляя пользователя набирать длинный текст в маленьком композере. не открывать редактор автоматически при простой смене типа.

**приёмка.** сменить тип в уже заполненном композере и вернуться обратно — текст, теги и папка не теряются. полный редактор получает тот же черновик, а выход возвращает его без создания дубликата. для пустого композера голосовая кнопка может оставаться микрофоном; для текста назначение основной кнопки должно изменяться понятно и с обновлением доступного имени.
