# 48 — кабинет остаётся на экране

[← оглавление](<README.md>)

[скриншот 48](<../test-results/screenshots/audit/48_back_from_account.png>)

**наблюдение.** тот же кабинет, перекрытие системного бара сохраняется. в исходном аудите это результат аппаратного back; сам кадр показывает лишь неизменность экрана, событие подтверждается только описанием теста.

**изменение — p1.** включить маршрут кабинета в единый обработчик возврата: при активной IME сначала закрывается она, затем верхний оверлей, затем маршрут возвращает в точку входа. не смешивать независимые подписки так, чтобы один back закрывал несколько слоёв или ни одного. не перехватывать выход с корня бесконечно.

**приёмка.** настройки → кабинет → системный back возвращает к синхронизации; повторить аппаратной кнопкой/жестом, с полем seed в фокусе и после отмены запроса входа. сохранённый несекретный черновик заметки не теряется. маршрут кабинета, открытый напрямую без истории, имеет явный безопасный возврат в основное приложение. не считать все back-сценарии сломанными: проблема локальна этому переходу по данным аудита.
