# 08 — поиск раздела синхронизации

[← оглавление](<README.md>)

[скриншот 08](<../test-results/screenshots/audit/08_settings_sync_visible.png>)

**наблюдение.** «синхронизация» стала видна после сдвига полосы, но выбранной остаётся форма провайдера. новый дефект формы не обнаружен; кадр подтверждает проблему обнаруживаемости разделов из 06–07, а не ещё один самостоятельный баг.

**изменение — p2.** в выборе разделов дать синхронизации полное имя и прямой доступ; при наличии состояния «нужен вход» показывать его рядом с названием/в самом разделе, не прятать за несколькими горизонтальными свайпами. не создавать дополнительный экран настроек ради этой одной ссылки.

**приёмка.** из корня настроек переход в синхронизацию выполняется одним выбором раздела; заголовок, выбранность и содержимое после тапа согласованы. состояние очереди не обозначается только цветной точкой. существующую форму провайдера при этом не сбрасывать без согласованного поведения сохранения.
