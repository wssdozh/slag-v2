# 17 — подзадачи свёрнуты, а не переключены

[← оглавление](<README.md>)

[скриншот 17](<../test-results/screenshots/audit/17_subtask_toggled.png>)

**наблюдение.** список подзадач исчез, стрелка смотрит вниз, счётчик остался «1 из 3». значит видимое изменение — сворачивание секции, не изменение выполненности. верх карточки сдвинулся вниз при сохранении её нижнего края; это соответствует нижнему выравниванию ленты.

**изменение — p2.** всю строку «подзадачи: 1 из 3» сделать понятным отдельным раскрывающим контролом с состоянием `aria-expanded`; по названию действия различать «показать/скрыть подзадачи» и «выполнить». не отдавать этот же тап контейнеру карточки. при раскрытии удерживать контекст, не уводить на другой фрагмент длинной ленты.

**приёмка.** раскрытие/сворачивание не меняет markdown-чекбоксы, срок, счётчик и очередь содержательных изменений без причины. talkback сообщает раскрытость. в длинном списке после сворачивания пользователь не теряет текущую карточку; конкретный скачок прокрутки по этой паре статичных кадров не измерен.
