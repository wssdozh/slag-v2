# 14 — поиск после скрытия клавиатуры

[← оглавление](<README.md>)

[скриншот 14](<../test-results/screenshots/audit/14_search_keyboard_dismissed.png>)

**наблюдение.** клавиатура отсутствует, поиск остался открыт, результаты не пропали; поле всё ещё показывает каретку. свободная высота ниже списка не является дефектом. замечания к placeholder и иконкам — в 13б.

**рекомендация — сохранить поведение.** скрытие клавиатуры не должно автоматически закрывать поиск. не перефокусировать поле при изменении высоты viewport: иначе клавиатура всплывёт снова и пользователь застрянет в борьбе с интерфейсом.

**приёмка.** первый системный back при активной IME скрывает клавиатуру, следующий закрывает поиск; запрос, фильтр и позиция не сбрасываются только из-за resize. повторный тап в поле возвращает IME. каретка без IME допустима, сама по себе не означает ошибку фокуса.
