# 01 — входящие: шапка, карточки и пустой композер

[← оглавление](<README.md>)

[скриншот 01](<../test-results/screenshots/audit/01_inbox_header.png>)

**наблюдение.** подпись «лента входящих» пересекает горизонтальную границу шапки. два фильтра подписаны одинаково — «все», без пояснения различий. метаданные карточек мелкие и приглушённые; время в формате `12:17 PM` соседствует с русской датой. длинная подсказка композера обрезана после `(@ папка,`. иконки меню карточки выглядят маленькими, но фактическая область нажатия из кадра неизвестна.

**точечные изменения.**
1. **p1:** выделить заголовку и подзаголовку собственную высоту, рисовать разделитель под ними; отдельно проверить верхний системный inset, не подменять его фиксированным отступом на глаз.
2. **p2:** различить фильтры видимыми названиями по их реальному назначению; например, «тип: все» и «статус: все», только если именно такова их семантика. не добавлять догадку в интерфейс.
3. **p2:** оставить короткий placeholder «мысль, заметка или задача…», синтаксис папок/тегов показывать контекстно при вводе. не делать placeholder единственным доступным названием поля.
4. **p2:** выделить действиям карточки самостоятельные непересекающиеся зоны нажатия; иконку увеличивать необязательно. вторичную строку метаданных переносить предсказуемо, время форматировать по выбранной локали/системным настройкам.

**приёмка.** на ширине 369 css px и увеличенном системном шрифте разделитель не проходит по тексту; различие фильтров понятно без открытия; подсказка не обрывается посреди инструкции; тап по краям зоны меню не открывает запись и не переключает подзадачу. проверить доступные названия через talkback. поведение отправки и сохранения этим кадром не проверено.
