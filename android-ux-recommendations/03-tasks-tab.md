# 03 — задачи: статусы и метаданные

[← оглавление](<README.md>)

[скриншот 03](<../test-results/screenshots/audit/03_tasks_tab.png>)

**наблюдение.** статусы обрезаны до «к вы…» и «в раб…», хотя именно они задают текущий список. в карточках сырые подписи `HIGH`, `MEDIUM`, `LOW` и даты `2026-11-05`; это не согласовано с языком интерфейса. счётчики 5 + 1 + 0 + 0 согласуются с общим числом 6 — здесь исправлять нечего.

**изменения.** **p1:** не сжимать названия четырёх статусов до многоточия: горизонтальная полоса вкладок с полной шириной текста и автопрокруткой выбранной вкладки в видимую область. альтернативу «делать / в работе / готово / бэклог» использовать только при сохранении смысла статусов. **p2:** переводить приоритеты в отображении («высокий», «средний», «низкий»), не менять сериализованные значения данных; даты показывать локализованно, сохранив полный год в доступном описании при необходимости. приоритет уже обозначен текстом, это сохранить — одного цвета недостаточно.

**приёмка.** на 320–369 css px и увеличенном шрифте ни один статус не теряет смысл; все вкладки достижимы жестом и talkback, выбранность объявляется. длинное название задачи не вытесняет меню за экран. сегодняшнюю/просроченную дату проверять по часовой зоне устройства, а не по времени из имени файла. добавление задачи из списка и нижний плюс должны иметь понятные назначения; различие действий пока не установлено.
