# 13б — открытый поиск с клавиатурой

[← оглавление](<README.md>)

[скриншот 13б](<../test-results/screenshots/audit/13_search_modal_open.png>)

**наблюдение.** поиск открыт, поле сфокусировано, результаты видны над клавиатурой. длинная инструкция placeholder обрезана после «для»; у первого результата нарисован символ enter. фильтр «таски» отличается от названия раздела «задачи». все задачи показаны жёлтой иконкой с галочкой, хотя по предыдущим кадрам часть не выполнена: это может быть иконка типа, не состояние выполнения.

**изменения — p2.** короткая подсказка «поиск по заметкам», отдельный понятный вход в команды вместо обязательного знания `>`. скрывать необязательный enter-маркер для сенсорного сценария, не отключая аппаратную клавиатуру. унифицировать «задачи». отличать иконку типа задачи от интерактивного чекбокса и от выполненности, чтобы результат поиска не обещал ложное состояние; доступное описание должно передавать реальный статус. папку у длинных результатов перенести во вторичную строку, если она отнимает место у названия.

**приёмка.** поиск по кириллице, пустому запросу и запросу без совпадений выдаёт различимые состояния. тап по результату открывает запись, а не завершает задачу из-за иконки; ввод не перекрывается IME. поиск/команды доступны без физической клавиатуры. наличие восьми строк над клавиатурой не доказывает достижимость остальных — проверить прокрутку до последнего результата.
