# 43 — ассистент с контекстом папки, не настройки

[← оглавление](<README.md>)

[скриншот 43](<../test-results/screenshots/audit/43_settings_from_dock.png>)

**наблюдение.** открыт ассистент «карьера», а не настройки. контекст явно указан сверху и в пустом состоянии — полезное отличие от скрытой папки назначения композера. при этом быстрый запрос «сводка хранилища» звучит шире выбранной папки. остальные замечания к шапке и техническим алиасам — в 05.

**изменения — p2.** согласовать подписи быстрых запросов с областью действия: «сводка папки», если ограничение действительно действует, либо явно предложить переключение на всё хранилище. выбор контекста должен быть проверяемым, не декоративным. не фиксировать «настройки открывают ассистента» лишь по имени файла.

**приёмка.** запрос по папке использует только разрешённую область и показывает источники; переход к глобальному контексту явный. back возвращает в ожидаемую папку/раздел, не меняя её данные. тап по шестерёнке открывает настройки один раз; событие дока требуется воспроизвести отдельно.
