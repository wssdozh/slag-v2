# Общий словарь: «таска» вместо «задача»

[← оглавление](../README.md) · пункты [03](../03-tasks-tab.md), [24](../24-composer-input-active.md), [25](../25-composer-input-active.md)

## что было

Один и тот же тип записи назывался тремя способами: «Таска» в фильтрах и селекторе типа, «Задача» в заголовке экрана, плейсхолдерах редактора и подсказках, «Таски» в доке. Пользователь видел это на одном экране.

## решение

По твоему выбору — везде **«таска»**. Правка сделана в общих компонентах, поэтому одинаково на телефоне и десктопе.

Заменено: `Название задачи…` → `Название таски…`, сроки/длительность/повтор «задачи» → «таски», `Создать задачу` → `Создать таску`, `Показать выполненные задачи` → `…таски`, `Изменить статус задачи` → `…таски`, `Черновик задачи` → `Черновик таски`, заголовок экрана `Задачи` → `Таски`, тосты календаря и фолбэк-заголовок `Задача` → `Таска`.

## что не трогала

- **«Подзадачи»** — это не тип записи, а часть структуры; менять на «подтаски» означало бы лезть в модель данных и терминологию редактора без твоего решения.
- тексты в MCP-инструментах и промптах — это API для внешних агентов, не интерфейс.

## проверка

`tsc -b` и `oxlint` чистые, `vite build` проходит. Визуально проверю на следующем кадре экрана тасок.

**риск:** новые записи без заголовка получают название «Новая таска» вместо «Новая задача». Существующие файлы не переименовываются — это важно, я не трогаю пользовательские данные.
