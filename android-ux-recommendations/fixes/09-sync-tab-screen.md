## что изменено и исправлено

1. **Честные лимиты:** устранены надписи «1 из 0 устройств» и «кеш 0 / 0 МБ». Добавлен признак `limitsKnown = Boolean(account) || maxDevices > 0`. До входа в аккаунт выводятся честные статусы: «лимиты устройств — после входа» и «кеш не синхронизирован».
2. **Иконка устройства по платформе:** на телефоне выводится `Smartphone` вместо десктопного `Laptop`.
3. **Имя по умолчанию:** для мобильной платформы дефолтное имя устройства — «Мой телефон» вместо «Мой ПК».
4. **Подпись режима:** «Полный доступ» заменён на «Чтение и запись» с подсказкой «Локальный режим синхронизации этого устройства».

## проверка

На устройстве: отображается иконка смартфона, статус «Чтение и запись», честные лимиты без нулей.

**десктоп:** На десктопе сохранена иконка ноутбука и название «Мой ПК».
