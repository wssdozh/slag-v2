# 09 — «1 из 0 устройств» и «кеш 0 / 0 МБ»

[← оглавление](../README.md) · [исходная рекомендация](../09-sync-tab-screen.md)

**до:** [скриншот аудита](<../../test-results/screenshots/audit/09_sync_tab_screen.png>) — до входа интерфейс показывал «1 из 0 устройств», «кеш 0 / 0 МБ» и «полный доступ», как будто лимиты равны нулю, а права подтверждены сервером.

**после:** ![после](<shots/09-after.png>)

## причина

`maxDevices`, `usedCacheMb`, `maxCacheMb` берутся из кеша подписки. Без входа кеш пустой, значения приходят нулями — и печатались как настоящие лимиты. Ноль здесь означает «неизвестно», а не «нельзя».

## что изменено

`SyncSettingsTab`: добавлен признак `limitsKnown = Boolean(account) || maxDevices > 0`. Пока лимиты неизвестны, строка статуса говорит «лимиты устройств — после входа» и «кеш не синхронизирован», а в заголовке «Устройства» остаётся только число локальных. Кнопка «Привязать устройство» получила `whitespace-nowrap shrink-0`, иначе длинный текст ломал строку на две.

## проверка

- на устройстве: «из 0» и «0 МБ» в разметке отсутствуют, «лимиты устройств — после входа» и «кеш не синхронизирован» присутствуют.
- «Устройства 1», кнопка привязки в одну строку.

**осталось:** подпись «Полный доступ» у локального устройства по-прежнему звучит как серверное право, хотя это локальный режим. Разделять «локальный доступ» и «права на сервере» — отдельная правка, в этот диф не входит.
