## что изменено

Шапка подсказок была скопирована в трёх меню (`FolderSuggestionMenu`, `TagSuggestionMenu`, `SlashCommandMenu`) слово в слово. Вместо трёх правок добавлен один компонент `SuggestionMenuHeader`: заголовок с иконкой плюс блок подсказок, который виден только при точном указателе — `hidden [@media(pointer:fine)]:flex`.

## проверка

- на устройстве в шапке осталось только «ЦЕЛЕВАЯ ПАПКА», список папок стал выше.
- на десктопе подсказка «Enter применить» на месте (проверено в chromium 1280×800), то есть знание клавиатурных сочетаний не потеряно.
- аппаратные клавиши продолжают работать: скрыт только текст подсказки, обработчики не тронуты.
