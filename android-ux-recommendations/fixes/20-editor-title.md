## что изменено

`FullscreenEditor`: `<input type="text">` → `<textarea rows={1}>` с `[field-sizing:content]`. Текст переносится и поле растёт по высоте; JS-ресайз не понадобился — свойство поддерживает WebView Chrome 156. Enter больше не вставляет перевод строки в заголовок, а переводы строк из вставки схлопываются в пробел, чтобы заголовок оставался однострочным по смыслу.

## проверка

- на устройстве заголовок занимает две строки, `scrollWidth == clientWidth == 335` (CDP) — горизонтального среза нет.
- ввод, сохранение и повторное открытие записи не изменились: правится только представление.
