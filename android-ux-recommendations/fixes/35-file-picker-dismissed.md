## что изменено и исправлено

1. **Сохранение черновика при выходе из пикера:** отмена нативного диалога выбора файлов не стирает набранный текст заметки и не сбрасывает выбранный тип.
2. **Безопасная обработка отмены:** отсутствие выбранных файлов обрабатывается как нейтральная отмена без показа ошибок.

## проверка

Подтверждено: после возврата из пикера текст `TestNoteAndroid` остаётся в поле ввода.

**десктоп:** Поведение идентично на десктопе.
