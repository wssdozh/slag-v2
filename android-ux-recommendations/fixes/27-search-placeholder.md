# 13б — обрезанная подсказка поиска

[← оглавление](../README.md) · [исходная рекомендация](../13b-search-modal-open.md)

**до:** [скриншот аудита](<../../test-results/screenshots/audit/13_search_modal_open.png>) — «Поиск по заметкам или введите '>' для» обрывается на 369 px.

**после:** подсказка целиком помещается: «Поиск по заметкам».

## что изменено

`SearchModal`: длинный placeholder с инструкцией про `>` заменён коротким. Сама команда не выброшена из продукта — на десктопе рядом остаётся монограмма-подсказка, а ввод `>` работает как раньше. Добавлен `enterKeyHint="search"` — на клавиатуре Android появляется кнопка «поиск» вместо возврата каретки.

## проверка

- `tsc -b`, `oxlint` чистые; подсказка не содержит обрыва.
- поиск по вводу работает как прежде; команда `>` обрабатывается тем же кодом.

**десктоп:** поведение не менялось, инструкция про `>` осталась в монограмме и в обработчике.
