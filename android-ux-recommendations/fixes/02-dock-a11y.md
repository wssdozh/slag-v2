# 02 — синяя точка в доке без объяснения

[← оглавление](../README.md) · [исходная рекомендация](../02-after-back-key.md)

**до:** [скриншот аудита](<../../test-results/screenshots/audit/02_after_back_key.png>) — на иконке «Папки» синяя точка, смысл которой нигде не назван; для скринридера это пустая декорация.

## что изменено

У точки был только `title` на `<span>` — этот текст не читается ни скринридером, ни по фокусу. Теперь число неразобранных записей попадает в доступное имя самой кнопки: `Папки, 1 неразобранных записей`. Визуально ничего не поменялось.

## проверка

- в браузере 375×812 доступное имя кнопки: `"Папки, 1 неразобранных записей"`.
- когда неразобранных нет, имя остаётся просто «Папки».
