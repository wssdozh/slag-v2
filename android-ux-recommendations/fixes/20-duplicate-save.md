# 20 — две кнопки «Готово» в редакторе

[← оглавление](../README.md) · [исходная рекомендация](../20-focus-editor-opened.md)

**до:** [скриншот аудита](<../../test-results/screenshots/audit/20_focus_editor_opened.png>) — «Готово» в шапке и «✓ Готово» в нижней панели, оба на одном экране.

**после:** ![после](<shots/20-single-save.png>)

## причина

Это не два разных действия: обе кнопки вызывают один `handleSave`. Дубль появился потому, что нижняя мобильная панель и шапка рендерятся на телефоне одновременно.

## что изменено

Верхняя кнопка сохранения скрыта на мобильном (`hidden md:flex`) — на десктопе она остаётся основной. Нижняя теперь подписана по состоянию: «Создать» для нового черновика, «Готово» для существующей записи — раньше для черновика она врала.

## проверка

- на устройстве в открытом редакторе одна видимая кнопка сохранения (`w: 91`), вторая в DOM имеет ширину 0 — то есть действительно скрыта, а не просто не видна.
- заголовок по-прежнему переносится (правка из этого же файла, 20).

**десктоп:** шапка с «Готово» и иконкой дискеты не изменилась, `hidden md:flex` её не трогает.
