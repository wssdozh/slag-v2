## что изменено и исправлено

1. **Сохранение меню при скрытии IME:** скрытие клавиатуры не сбрасывает введенный `@` и не закрывает всплывающее меню выбора папки.
2. **Управление через tap:** выбор папки тапом срабатывает детерминированно по атрибуту `data-folder-item`.

## проверка

Проверено: список папок остаётся доступным для прокрутки и тапа при скрытой клавиатуре.

**десктоп:** Клавиатурная навигация `ArrowDown / ArrowUp / Enter` на десктопе сохранена.
