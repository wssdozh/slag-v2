# 23 — Escape закрывал меню и редактор одновременно

[← оглавление](../README.md) · [исходная рекомендация](../23-popover-dismissed.md)

**до:** [скриншот аудита](<../../test-results/screenshots/audit/23_popover_dismissed.png>) — после закрытия меню форматирования на экране сразу лента, то есть редактор тоже исчез.

## причина

Обработчиков Escape было два: локальный в редакторе и глобальный LIFO в `AppContext`, который закрывает верхний слой. Локальный закрывал меню, глобальный в том же событии закрывал редактор — один жест снимал два слоя.

## что изменено

`FullscreenEditor` слушает `keydown` в **capture-фазе**. Если открыт мобильный поповер, обработчик гасит событие (`stopPropagation`) и закрывает только поповер — глобальный Back его уже не видит. Если поповеров нет, редактор закрывается как раньше.

## проверка

- мобильный вьюпорт 375×812: первый Escape → меню закрыто, редактор **открыт** (`afterFirst: 1`); второй Escape → редактор закрыт (`afterSecond: 0`).
- десктоп 1280×800: Escape без поповеров закрывает редактор сразу (`open: 1 → after: 0`), поведение не изменилось.
- `tsc -b`, `oxlint`, `vite build` чистые.

**побочно:** это же объясняло «провал» между кадрами 21–23 в аудите, где меню и редактор исчезали одним движением.
