## что изменено и исправлено

1. **Разделение зон скрепки и отправки:** благодаря увеличенному зазору (10 px) палец пользователя больше не задевает край кнопки прикрепления файлов при нажатии на отправку.
2. **Нативный файловый диалог:** вызов Android `PickActivity` происходит только по прямому осознанному тапу по скрепке.

## проверка

Проверено: тап по кнопке отправки отправляет запись и не вызывает системный файловый пикер.

**десктоп:** Десктопное открытие диалога файлов работает через Tauri dialog plugin.
