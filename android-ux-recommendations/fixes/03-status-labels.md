## что изменено

1. `MobileTasksView`: вкладки были `flex-1 min-w-0` с `truncate` — четыре равные колонки не оставляли места тексту. Теперь `shrink-0` с полными подписями, полоса прокручивается по горизонтали (`scrollWidth` 424 при `clientWidth` 343).
2. Приоритет выводился сырым значением enum. Добавлен общий словарь `PRIORITY_LABELS` в `src/lib/taskUtils.ts` — без копии в каждом компоненте.
3. Срок печатался как ISO. Используется существующий `formatDueDateLabel` из `dateUtils`: «Сегодня», «Завтра», «6 нояб.».

## проверка

- вкладки читаются полностью, счётчики на месте.
- в списке: «Завтра · Высокий», «Сегодня · Средний», «6 нояб. · Средний».

**десктоп:** мобильный список задач — отдельный экран, `ItemCard` и Kanban не тронуты; формат даты и словарь приоритетов общие для обеих платформ.
