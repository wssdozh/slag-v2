# 23 — уже лента, а не только закрытый popover

[← оглавление](<README.md>)

[скриншот 23](<../test-results/screenshots/audit/23_popover_dismissed.png>)

**наблюдение.** на экране нет ни меню, ни редактора: открыт прежний экран папки. это большее изменение, чем обещает имя файла. карточка визуально похожа на 17, но сохранность всего текста из свёрнутой карточки проверить нельзя.

**рекомендация — p1, проверить переход.** воспроизвести точную последовательность back из редактора с открытым меню. одно событие должно закрывать только верхний слой; следующий выход — редактор с сохранением. текущий кадр не доказывает, что оба слоя закрылись одним событием: между снимками могли быть несколько действий.

**приёмка.** отдельно записать back, тап вне меню и кнопку «готово»; сопоставить число действий с закрытыми слоями. после выхода вновь открыть запись и сверить текст/подзадачи/метаданные; не полагаться на сходство карточки. не править LIFO до воспроизведения.
