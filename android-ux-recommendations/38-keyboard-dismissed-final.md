**наблюдение.** статья осталась в ленте, композер пустой, шапка восстановилась. дубль заголовка/превью сохраняется. новых дефектов сверх 37 не видно.

**рекомендация — сохранить.** изменение viewport не должно пересоздавать карточку с новым id или возвращать уже отправленный черновик. сохранённый тип «статья» для следующей записи допустим, если это последовательное продуктовое решение; не сбрасывать его случайно только из-за закрытия клавиатуры.

**приёмка.** несколько циклов открытия/скрытия IME и переход в другую папку не дублируют запись. счётчик папки отражает новое количество; пустой композер не восстанавливает старый отправленный текст после перезапуска. повтор содержимого внутри одной карточки не смешивать с дубликатом записи.
