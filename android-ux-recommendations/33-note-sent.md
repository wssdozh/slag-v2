# 33 — текст ещё в композере, отправка не подтверждена

[← оглавление](<README.md>)

[скриншот 33](<../test-results/screenshots/audit/33_note_sent.png>)

**наблюдение.** `TestNoteAndroid` остаётся в поле, новой карточки нет, клавиатура скрыта. название «note sent» не доказывает сохранение. это может быть лишь скрытие IME, незавершённая операция или ошибка — причина не установлена.

**изменение — p1.** различать состояния «редактирование / сохраняем / сохранено / ошибка» и не заставлять пользователя повторно жать кнопку из-за отсутствия обратной связи. при скрытии клавиатуры сохранять набранное — здесь визуально это выполнено. если создание идёт долго, показывать процесс на кнопке без скачка её геометрии.

**приёмка.** после реального подтверждения создания появляется ровно одна запись либо понятная ошибка с сохранённым черновиком. до подтверждения текст не исчезает без возможности восстановления. повторный тап во время обработки не создаёт дубль. для этого кадра не фиксировать «отправка не работает» без записи нажатия и результата операции.
