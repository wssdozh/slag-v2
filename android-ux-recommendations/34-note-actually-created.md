# 34 — открылось системное приложение файлов

[← оглавление](<README.md>)

[скриншот 34](<../test-results/screenshots/audit/34_note_actually_created.png>)

**наблюдение.** видна заставка приложения файлов, а не созданная заметка. это согласуется с описанным в аудите открытием пикера, но само изображение не определяет вызвавшую кнопку и не доказывает промах пальца.

**изменение — p1 при воспроизведении.** проверить маршрутизацию тапа и реальные области скрепки/создания, затем развести их без пересечения. открывать системный выбор только по явному прикреплению; не запускать его побочным эффектом создания. использовать системный пикер вместо запроса широкого доступа ко всем файлам.

**приёмка.** записать тап по центру и краям обеих кнопок с координатами; создание не запускает файловую activity. отмена системного выбора возвращает тот же текст, тип и папку; успешный выбор добавляет вложение, но сам не публикует запись. заставку не использовать как доказательство созданной статьи.
