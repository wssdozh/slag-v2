# 02 — список папок после возврата

[← оглавление](<README.md>)

[скриншот 02](<../test-results/screenshots/audit/02_after_back_key.png>)

**наблюдение.** список папок читаемый, строки просторные, заголовок уже ниже системных значков. разделитель шапки проходит через нижнюю часть квадратного знака приложения. нижняя навигация состоит из иконок без подписей; у папки синяя точка без видимого объяснения. одновременно доступны создание папки сверху и отдельный плюс снизу — их назначение визуально различается лишь иконками.

**изменения — p2.** опустить разделитель ниже содержимого шапки; добавить короткие подписи основных разделов нижней навигации либо иной постоянно видимый способ понять назначение (не tooltip по долгому нажатию). дать нижнему плюсу доступное имя по реальному действию; при первом использовании кратко объяснить отличие от создания папки. синюю точку оставлять только с определённой семантикой и доступным текстовым эквивалентом, не объявлять её ошибкой синка по одному цвету.

**приёмка.** новый пользователь без подсказок отличает задачи, ассистента и настройки; talkback произносит название и выбранность раздела, а не «кнопка». каждая строка папки нажимается целиком. кадр показывает экран назначения, но сам по себе не подтверждает, каким событием туда вернулись; back проверяется отдельным сценарием.
