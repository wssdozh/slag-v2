**наблюдение.** снова пустой ассистент папки «карьера», новых визуальных состояний нет. отсутствие сообщений нельзя трактовать как очистку истории: на 43 она тоже пустая.

**рекомендация — без отдельного исправления.** использовать замечания 05 и 43, не заводить повторные задачи по одному и тому же экрану. при проверке перехода в настройки фиксировать нажатую кнопку, а не только следующий «current».

**приёмка.** один тап по шестерёнке, кадр после завершения перехода, затем возврат с непустым запросом. если меню не откроется, снять геометрию target и обработчик события; сейчас неисправность кнопки не доказана.
