# 16 — фактически «карьера», не «проекты»

[← оглавление](<README.md>)

[скриншот 16](<../test-results/screenshots/audit/16_projects_folder.png>)

**наблюдение.** несмотря на имя файла, шапка и карточка относятся к «карьере». показана задача с тремя подзадачами, одна выполнена; «1 из 3» соответствует картинке. между фильтрами и единственной записью большое свободное пространство, карточка прижата ближе к композеру. это может быть намеренная чатоподобная лента, не безусловный дефект. подзаголовок просто повторяет имя папки и пересекает разделитель.

**изменения — p2.** убрать бессодержательный повтор названия, исправив при этом высоту общей шапки, а не только скрыв симптом. нижнее выравнивание ленты **сохранить**: это контракт потока-монолога, а не дефект; отзыв старого предложения о старте сверху — см. раздел «рамки». область меню карточки, сворачивания подзадач и чекбоксов сделать независимой; перенос длинной подзадачи не должен уменьшать её зону нажатия.

**приёмка.** тап по любой из трёх подзадач меняет только её статус, не открывает редактор и не завершает родителя; счётчик обновляется согласованно. отдельно проверить меню по краям области. подпись «сегодня» относится к группировке ленты, а «7 ноя» может быть сроком — не объявлять их противоречием, пока не определена семантика дат. исходный аудит использовал этот файл как пример карточки, но название папки в рекомендациях исправлено по изображению.
