# 19 — реальная шторка действий записи

[← оглавление](<README.md>)

[скриншот 19](<../test-results/screenshots/audit/19_long_press_card.png>)

**наблюдение.** меню открыто, запись названа, удаление выделено текстом и цветом, есть отмена — это удачные опоры. присутствует «открыть в проводнике», две разновидности копирования ссылки с жаргоном «фулл / [[линк]]» и сетка из четырёх действий с переносом «фокус-редактор». много вложенных обводок. нижняя отмена видима, но при увеличенном шрифте места станет меньше.

**изменения.** **p1:** показывать «открыть в проводнике» только при реальной поддержке открытия доступного пользователю каталога. для sandbox-хранилища android скрыть неподдерживаемое действие; «поделиться файлом» — отдельная функция с корректным native content URI, не притворная замена вызовом desktop API или обещанием Web Share без проверки WebView. **p2:** «копировать ссылку на запись» и «копировать внутреннюю ссылку» с кратким пояснением различия; «открыть редактор» вместо ломаной длинной подписи. тип записи оформить одним простым переключателем без дополнительных вложенных карточек.

**приёмка.** меню прокручивается при увеличенном шрифте; отмена/back/тап по фону закрывают только его, не активируют карточку под ним. фокус talkback остаётся в шторке до закрытия. смена типа с задачи на заметку не уничтожает подзадачи молча. удаление обратимо через корзину/отмену; скопированная ссылка проверяется в целевом приложении и не обещает открытие на другом устройстве до доступности записи там. не добавлять drag-жест закрытия, если уже есть достаточные кнопки и back; видимая ручка не доказывает поддержку свайпа.
