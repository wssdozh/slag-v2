# 27 — автокомплит папки: клавиатурная инструкция занимает шапку

[← оглавление](<README.md>)

[скриншот 27](<../test-results/screenshots/audit/27_folder_autocomplete.png>)

**наблюдение.** при одном `@` открыты папки, текущая явно подписана. инструкция `↑↓ / Enter / Esc` занимает две строки, хотя активна экранная клавиатура. список и композер полностью выше IME. кнопка отправки уже активна при одном служебном символе.

**изменения.** **p2:** на сенсорном вводе заменить инструкцию коротким «выберите папку» или убрать её; поддержку внешней клавиатуры сохранить, подсказку показывать по актуальному способу ввода. **p1, проверить:** определить допустимость отправки одного `@` и пустого тела после разбора метаданных. не создавать пустую статью из одного выбора папки; если одиночный `@` намеренно считается обычным текстом, это отдельный допустимый случай, не блокировать все такие символы безусловно.

**приёмка.** тап по папке применяет её один раз, закрывает список и сохраняет текст/каретку. проверить вложенные и длинные имена, фильтрацию кириллицей, ноль совпадений и прокрутку. back отменяет подсказку, не публикует текст; аппаратный enter при открытом автокомплите выбирает пункт, не отправляет запись. отсутствие содержательного тела после применения метаданных даёт понятную неактивную отправку, если пустые записи продуктом не поддерживаются.
