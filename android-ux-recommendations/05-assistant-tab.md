# 05 — ассистент: область данных и настройки запроса

[← оглавление](<README.md>)

[скриншот 05](<../test-results/screenshots/audit/05_assistant_tab.png>)

**наблюдение.** идентификатор модели пересекает разделитель шапки, как подзаголовок в кадре 01. подписи `agenda`, `search`, `task`, `stats` дублируют понятные русские действия. внизу рядом стоят «локальный», `R: Low` и глобус без объяснения: нельзя понять, где выполняется запрос и передаются ли заметки наружу. сам факт внешней передачи этим кадром не доказан.

**изменения.** **p1:** развести название, модель и границу шапки по вертикали. **p2:** убрать технические алиасы у готовых запросов, если они не нужны для пользовательского действия. заменить `R: Low` понятным названием фактического параметра (например, «глубина рассуждения: низкая», только если это действительно reasoning). явно разделить область поиска «всё хранилище» и место обработки запроса; глобусу дать название и видимое состояние. не называть облачную обработку локальной лишь потому, что заметки хранятся на телефоне.

**приёмка.** до отправки пользователь может определить выбранный источник данных, провайдера/место обработки и включён ли веб-поиск. модель длиннее текущей не перекрывает кнопки. настройки раскрываются без потери текста запроса; недоступная отправка имеет объяснение при ошибке конфигурации, а не только серую иконку. сценарий создания задачи ассистентом должен завершаться подтверждением, а не незаметной записью в хранилище; по этому пустому чату его работа не установлена.
