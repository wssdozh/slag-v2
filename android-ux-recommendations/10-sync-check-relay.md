# 10 — проверка сервера: результат не виден

[← оглавление](<README.md>)

[скриншот 10](<../test-results/screenshots/audit/10_sync_check_relay.png>)

**наблюдение.** относительно 09 у кнопки «проверить» и поля сервера нет видимого результата. из этого нельзя заключить, что запрос не выполнялся: кадр мог быть снят до ответа либо после исчезновения уведомления.

**изменение — p1.** выводить результат рядом с сервером, а не только временным тостом: «проверяем…» → «сервер доступен; для синхронизации нужен вход» либо конкретная ошибка. различать сетевую доступность, требование авторизации и успешный обмен заметками. не показывать «синхронизировано» по одному успешному health-check. повторную кнопку блокировать только на время текущей проверки, после ошибки давать повторить.

**приёмка.** проверить тайм-аут, отсутствие сети, неверный URL, ответ с требованием входа и доступный сервер. результат остаётся читаемым после завершения и объявляется talkback без уноса фокуса. очередь не очищается при проверке соединения. при изменении URL старый успех сбрасывается или явно относится к предыдущему адресу.
