# 49 — возврат по названию файла всё ещё не состоялся

[← оглавление](<README.md>)

[скриншот 49](<../test-results/screenshots/audit/49_back_to_app.png>)

**наблюдение.** кабинет остаётся видимым; верхняя ссылка возврата пересекается с системными значками. факт нажатия на неё и его координаты неизвестны. отдельную неисправность ссылки по этому кадру не устанавливаем.

**рекомендация — p1.** возврат должен быть доступен обычной кнопкой в безопасной области, не требовать точного попадания между иконками android. после устранения геометрии проверить сам маршрут; не маскировать отсутствие back только добавлением ещё одной ссылки с перезагрузкой.

**приёмка.** возврат кнопкой и системным back приводит в одну ожидаемую точку, не отправляет пустую форму, не создаёт новую сессию входа и не открывает браузер. после возврата кабинет не появляется снова из-за запоздалого результата запроса.
