# Дорожная карта SLAG v2 (ROADMAP)

> Сервер синхронизации и telegram-бот вынесены в
> [wssdozh/slag-relay](https://github.com/wssdozh/slag-relay); упоминания `slag-relay` ниже
> исторические.

## Видение продукта
SLAG v2 — ультраминималистичная, быстрая и полностью локал-фёрст система заметок, объединяющая строгую эстетику **Linear Dark**, эргономику потока **Telegram** и расширяемую структуру **Obsidian** (Markdown + YAML Frontmatter) с нулевым доверием к внешним серверам (Zero-Knowledge E2EE).

## Детализация Этапа 4: Сквозная E2EE-синхронизация

### 4.1. Сервер ретрансляции (Zero-Knowledge Relay Server)
- [x] Архитектурное проектирование: модель Non-Storage Relay (эфимерный FIFO почтовый ящик, отсутствие постоянной БД заметок).
- [x] Разработка сервиса `slag-relay` на стандартной библиотеке Python 3 (asyncio + WebSocket + SQLite):
  - WebSocket-комнаты по слепому `SyncRoomId = HMAC-SHA256(VaultKey, "slag-relay-room-v1")`.
  - Мгновенная ретрансляция пакетов онлайн-девайсам (latency < 20 мс).
  - Эфимерный кеш недоставленного для офлайн-устройств с ограничением квоты (1 ГБ по умолчанию) и защитой от DoS (HTTP 413).
  - Моментальное удаление пакетов из SQLite сразу по получению подтверждения (`ACK`).
  - Эндпоинты для сопряжения устройств по 6-значному PIN с защитой от перебора (IP rate-limiting).
- [x] Развертывание инстанса на боевом VPS `netcup-server` (152.53.199.71:8320) под управлением systemd (`slag-relay.service`).
- [x] Поддержка подключения пользовательских серверов (Self-hosted mode) с проверкой соединения на лету.

### 4.2. Протокол пакетирования дельт (SyncBundle & Merkle State)
- [x] Полный охват синхронизируемых данных:
  - **Заметки (Items)**: контент `.md`, YAML-метаданные, подзадачи, дедлайны, приоритеты.
  - **Папки (Folders)**: структура дерева, иконки, цвета, AI-описания, порядок сортировки.
  - **Виды и настройки (Workspace & Views)**: канбан-колонки, `statusMapping`, режимы ленты и фильтрации.
  - **Вложения (Attachments)**: передача медиа-данных с дедупликацией.
- [x] Упаковка и шифрование:
  - Формирование пакета дельт `SyncBundle` только для измененных сущностей.
  - Сжатие текстового батча через Gzip (`fflate`).
  - Сквозное шифрование пакета на клиенте (AES-256-GCM, Web Crypto API) с уникальным nonce.
  - Мгновенная сверка состояния хранилища через корневой хеш `VaultStateHash` за 1 сетевой запрос.

### 4.3. Система доверенных устройств и сопряжение
- [x] Идентификация устройства: `DeviceID = slag-<pubkey-hash>`.
- [x] Безопасный сценарий сопряжения:
  - **6-значный PIN (Short Pairing Code)**: безопасный обмен ключами по коду `XXX-XXX` (TTL 5 мин).
  - **4-значный SAS-код (Short Authentication String)**: защита от MITM со сверкой контрольных цифр человеком.
  - **Подтверждение человеком (Human-in-the-Loop Approval)**: мастер-ключ передаётся гостю только после явного одобрения владельцем.
- [x] Защита от компрометации (Panic Re-keying):
  - Мгновенная ротация мастер-ключа хранилища (новая 12-словная мнемоника BIP-39).
  - Смена слепой комнаты `SyncRoomId` и полный сброс доступа у всех старых девайсов.
- [x] Управление правами устройств:
  - Инлайн переименование девайсов с хранением имён строго локально.
  - Переключение режимов: «Полный доступ» / «Только чтение» (receive-only гвард).
  - Флаг разрешения AI Lease на конкретном устройстве.

### 4.4. Интерфейс управления (Linear Dark 95% Fidelity)
- [x] Единая лаконичная карточка статуса: бейдж тарифа (`SLAG Smile`), live-индикатор, задержка (ping), квота кеша и ручная синхронизация.
- [x] Отдельное модальное окно привязки (`PairDeviceModal` в стиле 1Password):
  - Автоматическая генерация PIN при открытии без лишних промежуточных кликов.
  - Интуитивный переключатель `Показать PIN` / `Ввести PIN`.
  - Автоматический переход в карточку подтверждения SAS при вводе кода гостем.
- [x] Двухуровневая типографика доверенных устройств: без визуального перегруза, чипсов на чипсах и вложенных рамок.
- [x] Настройка энергосбережения смартфона: «Фоновая синхронизация» (Мгновенно / 10 минут / 30 минут).
- [x] Живой статус синхронизации в статус-баре сайдбара с цветным индикатором онлайна и переходом в настройки в 1 клик.
- [x] Линейка тарифов:
  - **Free** (0 ₽): 2 устройства, 1 ГБ кеша заметок без медиа-вложений;
  - **Smile** (199 ₽ / мес, хит): 5 устройств, 10 ГБ кеша заметок и фото, AI-триаж;
  - **Angry** (499 ₽ / мес): 15 устройств, 50 ГБ кеша, приоритетный AI Lease;
  - **Self-hosted** (0 ₽): открытый код, запуск через Docker на своём сервере.

### 4.5. Двухфакторная аутентификация (2FA) [Запланировано]

## Детализация Этапа 5: Распределенный AI Lease
- Межплатформенное делегирование тяжелых задач ИИ.
- Заметки, созданные на телефоне на бегу, получают статус `aiStatus: pending`.
- Десктоп, подключенный к электросети и быстрому интернету, автоматически берет временный `aiLease` (блокировку), выполняет разбор (автотеги, раскладку по папкам) и пушит результат обратно в синк.
- Исключение двойных списаний API-токенов и сохранение заряда батареи смартфона.
