# База знаний UI и логики работы приложения SLAG v2

Этот документ — эталонный источник правды по интерфейсу, интеракциям, жестам, горячим клавишам и логике работы приложения SLAG v2. Информация проверена непосредственно по исходному коду компонентов (`src/components/`, `src/lib/commands.ts`, `src/context/AppContext.tsx`).

---

## 1. Архитектура и концепция (`overview`)

- **Архитектура Local-First:** все данные пользователя хранятся на локальном диске в виде текстовых Markdown-файлов (`.md`) с YAML frontmatter.
- **Работа без сети:** приложение полностью автономно. Нет интеграций со сторонними сервисами (Google Calendar, Notion, Todoist Cloud). Все вычисления, индексация и планирование происходят локально.
- **Корневая папка «Входящие» (`inbox`):**
  - Главная точка сбора контента.
  - Когда активны «Входящие», глобальный поиск и ИИ-ассистент видят всё хранилище целиком.
  - При переходе в конкретную подпапку контекст поиска и работы ассистента сужается до выбранной папки.
- **Типы записей (`itemType`):**
  - `note` (Заметка) — короткая мысль, идея, конспект. В ленте рендерится как чистый текст без принудительного заголовка `<h3>`.
  - `task` (Задача) — дело со статусом (`backlog`, `todo`, `in_progress`, `done`), сроком (`dueDate`), точным временем напоминания (`reminder`), приоритетом (`none`, `low`, `medium`, `high`) и чеклистом подзадач (`subtasks`).
  - `article` (Статья) — структурированный лонгрид. В ленте отображает заголовок и краткий трехстрочный тизер, клик по которому открывает запись в полноэкранном редакторе.

## 2. Сайдбар и навигация (`navigation`)

- **Верхний блок:**
  - Закрепленная кнопка **«Входящие»** (`DEFAULT_INBOX_FOLDER`) с числовым счетчиком неразобранных записей. Клик переключает активную папку на Inbox.
- **Секция «Папки»:**
  - Кнопка с иконкой `+` (`FolderPlus`) в заголовке секции — открывает модальное окно создания новой папки (`openCreateFolderModal`).
  - **Дерево папок (`FolderTree`):**
    - Одиночный клик по папке — фильтрация центральной области по выбранной папке.
    - Стрелка `>` / `v` слева от имени папки — сворачивание и разворачивание дочерних подпапок.
    - Drag & Drop заметок на папку: перетаскивание карточки из ленты на строку папки в дереве мгновенно перемещает файл в эту папку (`moveItem`).
    - Правый клик (ПКМ) по папке открывает контекстное меню папки:
      - *Информация и медиа* — открывает профиль папки: иконка, имя, описание для ИИ, шесть счётчиков и медиатека. Имя, иконка, описание, перенос и удаление правятся прямо здесь же, инлайн.
      - *Создать подпапку* — открывает модалку создания вложенной папки.
      - *Проводник* — подменю открытия папки в системном проводнике ОС.
      - *Удалить папку* (недоступно для Inbox) — удаление папки с диска.
- **Нижняя панель сайдбара:**
  - **Селектор хранилищ (`VaultSwitcherMenu`):** отображает имя текущего хранилища. Клик открывает выпадающее меню со списком хранилищ, кнопками добавления локальной папки как нового хранилища или переключения между ними.
  - **Кнопка статуса синхронизации (`RefreshCw`):**
    - Светодиодный индикатор: зеленый с пульсацией (подключено, пинг в миллисекундах), вращающийся янтарный (идёт синхронизация дельт), серый (офлайн).
    - Клик открывает окно настроек на вкладке `sync`.
  - **Кнопка системных логов (`Terminal`):** открывает полноэкранный интерфейс диагностики и логов в реальном времени `LogViewer` (хоткей `mod+` `).
  - **Кнопка настроек (`Settings`):** открывает модальное окно настроек параметров ИИ, хранилища, темы и устройств (хоткей `mod+,`).

## 3. Режимы представления папки (`views`)

Расположены в шапке центральной панели (`FeedHeader`):
- **Селектор представлений (`ViewModeSwitcher`):**
  - Кнопка **«Лента»** (`Layers`) — хронологический стрим карточек записей.
  - Кнопка **«Канбан»** (`Kanban`) — доска задач с четырьмя фиксированными стадиями.
  - Кнопка **«Календарь»** (`Calendar`) — расписание дедлайнов с недельным таймлайном и сеткой месяца.
  *(Примечание: переключение режимов осуществляется кликом по кнопкам в шапке; глобальные хоткеи ⌘1-3 для видов не назначены).*
- **Кнопка ИИ-сортировки (`ArrowUpDown`):**
  - Появляется в шапке только при нахождении в папке «Входящие», если есть неразобранные записи.
  - Отображает счетчик неразобранных записей. Клик открывает модальное окно пакетной ИИ-сортировки `TriageModal`.
- **Кнопка «Вид и фильтры» (`MoreVertical`):**
  - Открывает модальное окно `FolderViewModal` для настройки локальной сортировки (по дате изменения, создания, заголовку) и постоянных фильтров текущей папки.

## 4. Панель быстрого ввода (`composer`)

Композер расположен внизу ленты (`Composer.tsx`):
- **Клавиши отправки:**
  - `Enter` (без Shift) — сохраняет и создает запись в текущей папке.
  - `Shift + Enter` — перенос строки без отправки.
- **Переключатель типа (слева):**
  - Выбор между Заметкой (`note`), Задачей (`task`) и Статьей (`article`).
- **Автокомплиты прямо в поле набора:**
  - Ввод символа `/` — открывает меню быстрого выбора папки сохранения.
  - Ввод `//` (или слэш-команд) — открывает меню слэш-действий (`SlashCommandMenu`).
  - Ввод `[[` — открывает автоподстановку вики-ссылок на существующие заметки хранилища.
  - Ввод `#` — открывает подсказку тегов из существующего словаря.
  - **Естественный парсер Todoist:** прямо в тексте можно указывать сроки («завтра в 10:00», «пн»), приоритеты (`p1` — высокий, `p2` — средний, `p3` — низкий), длительность («30м») и повторы («каждые 2 дня»). Композер автоматически выделит их в соответствующие поля задачи.
- **Инструменты ввода:**
  - **Кнопка микрофона (`Mic`):** запись аудио-заметки. Поддерживает клик для старта/стопа или удержание. Звук пишется в `.attachments/` и локально транскрибируется моделью Whisper.
  - **Кнопка видеокамеры (`Video`):** запись видеокружка 1:1 до 60 секунд. Поддерживает удержание пальца и сдвиг на замочек для фиксации режима записи.
  - **Кнопка `+Ai` (`Sparkles`):** запуск фонового подбора релевантных тегов для текста через модель Gemini Flash.
  - **Кнопка `Maximize2`:** переносит текущий черновик в полноэкранный Focus Editor.
  - **Кнопка скрепки (`Paperclip`):** выбор локальных файлов (изображения, аудио, документы) для прикрепления.
  - **Плашка ответа (`Reply Banner`):** отображается над полем ввода, если активен ответ на другую запись (`replyTarget`). Клик по крестику `X` сбрасывает ответ.

## 5. Карточки в ленте (`feed_and_cards`)

- **Карточка заметки (`note`):**
  - Отображает чистый текст Markdown без отдельного верхнего заголовка.
  - При наличии аудиозаписи отображается встроенный компактный аудиоплеер с таймлайном и кнопкой воспроизведения.
  - При наличии видеокружка отображается круглый плеер `VideoCirclePlayer`.
- **Карточка задачи (`task`):**
  - Слева круглый чекбокс: клик мгновенно переключает статус `todo` ↔ `done` (выполненная задача зачеркивается и приглушается).
  - Справа от чекбокса — заголовок и опциональный текст описания.
  - Блок подзадач: кнопка «Подзадачи: N из M» разворачивает список подзадач. Чекбокс каждой подзадачи кликабелен прямо в ленте без перехода в редактор.
- **Карточка статьи (`article`):**
  - Отображает заголовок с иконкой документа и краткий анонс текста (ограничен тремя строками `line-clamp-3`).
  - Клик по заголовку или тексту открывает статью в полноэкранном редакторе `FullscreenEditor`.
- **Интерактивные элементы карточки:**
  - Клик по тегу `#тег` — включает фильтрацию ленты по этому тегу.
  - Клик по вики-ссылке `[[Название]]` — плавно скроллит ленту к целевой карточке и подсвечивает её рамку импульсом.
  - Клик по миниатюре изображения — открывает полноэкранный просмотрщик `ImageLightbox`.
  - Правый клик (ПКМ) или кнопка «три точки» — открывает единое контекстное меню карточки.

## 6. Контекстное меню карточки (`context_menu`)

Вызывается по ПКМ или клику на кнопку «три точки» на карточке (`ContextMenu.tsx`):
- **Действия:**
  - *Ответить* (хоткей `r`) — привязывает запись как родительскую (`replyToId`) в нижнем композере.
  - *Открыть в Focus Editor* (хоткей `mod+e`) — открывает запись в полноэкранном редакторе.
  - *Закрепить / Открепить* (хоткей `p`) — фиксирует карточку в верхнем закрепленном баннере папки.
  - *Сменить тип записи* (хоткеи `1`, `2`, `3` или `n`, `t`, `a`) — быстрая конвертация между Заметкой, Задачей и Статьей.
  - *Копировать ссылку* (хоткей `mod+l`) — копирует в буфер вики-ссылку `[[Заголовок]]`.
  - *Копировать полную ссылку* (хоткей `mod+shift+l`) — копирует ссылку с идентификатором.
  - *Дублировать* (хоткей `mod+d`) — создает точную копию записи.
  - *Открыть в проводнике* (хоткей `o` или `mod+o`) — открывает физический файл `.md` в проводнике операционной системы.
  - *В корзину* (хоткей `Delete` или `Backspace`) — безопасно перемещает файл записи в папку `.trash/`.

## 7. Полноэкранный редактор (`editor`)

Компонент `FullscreenEditor.tsx` (Focus Editor):
- **Основа:** редактор построен на `@atomic-editor/editor` (CodeMirror 6). Представляет собой единое интерактивное поле с живым инлайн-рендером стилей (без разделения экрана на сплит-панели).
- **Шапка редактора:**
  - Поле редактирования заголовка.
  - Селектор типа записи (`note` / `task` / `article`).
  - Поповер выбора дедлайна `DatePickerPopover` (для задач).
  - Настройка интервала повтора (`RecurrenceRule`).
  - Селектор приоритета (`none`, `low`, `medium`, `high`).
  - Выбор папки для перемещения записи.
  - Список тегов с возможностью добавления и удаления.
- **Панель инструментов текста:**
  - Форматирование: жирный, курсив, зачеркнутый, H1, H2, списки (маркированный, нумерованный, чекбоксы задач), цитаты, код, таблицы.
  - Кнопка прикрепления файлов и вставки ссылок `![[файл]]`.
- **Автосохранение:** все правки автоматически сохраняются в черновик хранилища при вводе.
- **Закрытие:** клавиша `Escape` или клик по стрелке «Назад» в верхнем левом углу.

## 8. Канбан-доска (`kanban`)

Компонент `KanbanBoard.tsx`:
- **Стадии задач:** строго 4 фиксированные колонки статусов:
  1. `backlog` («Бэклог», иконка пунктирного круга).
  2. `todo` («К выполнению», иконка серого круга).
  3. `in_progress` («В работе», иконка полузакрашенного янтарного круга).
  4. `done` («Выполнено», иконка синей галочки в круге).
- **Интеракции:**
  - Drag & Drop карточек задач между колонками автоматически меняет статус задачи в файле.
  - Клик по названию статуса на карточке внутри доски открывает быстрое меню смены статуса.
  - Кнопка `+` в заголовке колонки открывает композер для создания задачи с уже предустановленным статусом этой колонки.
- **Колонка «Материалы» (ТРИЗ-панель):**
  - Выдвижная левая панель, открывается по кнопке с иконкой книги (`BookOpen`) в шапке канбана.
  - Содержит все заметки и статьи текущей папки и строку локального поиска по ним.
  - Перетаскивание заметки или статьи из колонки материалов в любую колонку задач мгновенно конвертирует её в задачу (`handleConvertToTask`) с назначением статуса целевой колонки.

## 9. Календарное расписание (`calendar`)

Компонент `CalendarView.tsx`:
- **Режимы отображения:**
  - **Режим недели (`week`):** активен по умолчанию. Показывает таймлайн с разбивкой по часам суток.
  - **Режим месяца (`month`):** классическая календарная сетка по дням месяца.
  - Переключение режимов: кнопки «Неделя» / «Месяц» в верхней панели календаря.
- **Интерактивный зум таймлайна недели:**
  - Высоту часового блока можно динамически растягивать от 36px до 140px.
  - Автоматическая привязка к сетке с шагом слотов 15, 30 или 60 минут.
- **Выдвижная боковая шторка задач:**
  - Открывается по кнопке с иконкой списка задач в шапке календаря.
  - Содержит две вкладки:
    - **«Просрочено» (`overdue`)** — задачи, дедлайн которых остался в прошлом.
    - **«Без даты» (`unscheduled`)** — задачи без назначенного поля `dueDate`.
- **Drag & Drop планирование:**
  - Перетаскивание задачи на строку конкретного часа вычисляет точное время с шагом в 15 минут и сохраняет его в поле напоминания `reminder` (ISO-формат) и дату в `dueDate`.
  - Перетаскивание в верхнюю полосу дня «Весь день» (`calendar-allday`) назначает дату `dueDate`, сбрасывая точное время `reminder`.
  - Перетаскивание карточки на ячейку в режиме месяца переносит дату дедлайна с сохранением времени суток, если оно было задано ранее.
  - Клик по свободной ячейке дня открывает композер для создания задачи с уже выбранной датой.

## 10. Поиск и ИИ-триаж (`search_and_triage`)

- **Глобальный поиск (`SearchModal`):**
  - Хоткей вызова: `mod+f` или `mod+k`.
  - Полнотекстовый нечеткий поиск на движке Orama BM25.
  - Индексирует не только markdown-текст и заголовки, но и текстовые расшифровки аудиозаписей (Whisper) и текст с картинок (OCR).
  - Встроенные фильтры:
    - По времени: `all` (все), `today` (сегодня), `yesterday` (вчера), `week` (неделя), `month` (месяц).
    - По типу записи: `all` (любые), `note` (заметки), `task` (задачи), `article` (статьи).
    - По папкам: ограничение области поиска конкретной директорией.
- **ИИ-триаж папки «Входящие» (`TriageModal`):**
  - Вызов: кнопка с иконкой `ArrowUpDown` и счетчиком в шапке Входящих (`FeedHeader`).
  - Модель анализирует накопившиеся во «Входящих» заметки и предлагает оптимальные папки назначения и теги на основе описаний папок в хранилище.
  - Безопасность: перенос выполняется только после явного подтверждения пользователем карточек предложений в модальном окне.

## 11. Синхронизация и безопасность (`sync_and_storage`)

- **Файловая система:**
  - Все заметки хранятся в открытом формате Markdown (`.md`).
  - Все прикрепленные медиафайлы (фото, аудиозаписи, видеокружки) сохраняются локально в подпапке `.attachments/`.
  - Удаленные записи физически переносятся в подпапку `.trash/`, откуда могут быть восстановлены или безвозвратно стерты.
- **Синхронизация (Relay Sync E2EE):**
  - Сквозное шифрование на базе шифра XChaCha20-Poly1305.
  - Сервер синхронизации релея выступает в роли «слепого почтальона» и хранит только зашифрованные дельты, не имея доступа к ключам и содержимому файлов.
- **Связывание устройств (`DevicesSettingsTab`):**
  - Открывается через «Настройки» (`mod+,`) → вкладка «Устройства».
  - Работает через механизм одноразовых PIN-кодов (без QR-кодов):
    1. На основном устройстве выбирается режим **Host** — генерируется 6-значный PIN-код, действующий 300 секунд (5 минут).
    2. На подключаемом устройстве выбирается режим **Guest** — вводится этот 6-значный PIN.
    3. На экранах обоих устройств появляется 4-значный короткий код подтверждения (SAS). Пользователь сверяет их глазами и подтверждает связывание.
    4. Ключи хранилища безопасно шифруются публичным ключом нового устройства и передаются по защищенному каналу.

## 12. Мобильный интерфейс Android (`mobile`)

Компоненты `MobileShell.tsx` и `MobileFloatingDock.tsx`:
- **Нижний плавающий док (Floating Linear Dock):**
  - Островная капсула внизу экрана с переключением разделов:
    - `folders` («Папки») — дерево папок и просмотр стрима выбранной папки. Если во Входящих есть неразобранные записи, на иконке отображается синяя точка-индикатор.
    - `tasks` («Таски») — специализированный список задач с фильтрами.
    - `assistant` («ИИ») — полноэкранный диалог с ИИ-ассистентом.
    - `settings` («Настройки») — параметры хранилища, аккаунта и синхронизации.
    - `calendar` («Календарь») — мобильный просмотр календаря дедлайнов.
    - `audio` («Плеер») — плеер для прослушивания голосовых заметок.
- **Кнопка быстрого создания (FAB):**
  - Круглая кнопка с иконкой `+` справа от плавающего дока. Мгновенно открывает форму создания новой записи в текущей активной папке.
- **Экран папки (`MobileFolderInfoView`):**
  - Открывается на весь экран по тапу на название папки: иконка, имя, описание для ИИ, шесть счётчиков и медиатека. Отдельной формы правки нет — имя, иконка, описание и родитель меняются тапом по самому элементу.
