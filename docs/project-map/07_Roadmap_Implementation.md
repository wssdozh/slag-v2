## 🧪 Протокол верификации и тестирования

Каждый релиз проходит обязательный 3-ступенчатый контроль качества:
1. **Статический анализ (`npm run lint`)**: проверка линтером `oxlint` на отсутствие невалидных хуков, утечек памяти и нежелательных синхронных вызовов `setState`.
2. **E2E-тестирование (`npx playwright test`)**: сквозные автоматические сценарии Playwright:
   - Создание заметки по нажатию `Enter`.
   - Создание и выполнение чекбоксов задачи прямо в ленте.
   - Переключение 3 режимов Inbox («Неразобранные», «Все», «Разобранные»).
   - Раскрытие инлайн-аккордеона статьи и Focus Editor.
   - Вызов контекстного меню и закрепление записей.
   - Полноэкранная галерея Lightbox и листание картинок.
   - LIFO-закрытие слоев по клавише `Escape`.
   - Ресайзинг панелей мышью.
3. **Сборка продакшн-бандла (`npm run build`)**: подтверждение чистоты типов TypeScript и успешной компиляции Vite.
