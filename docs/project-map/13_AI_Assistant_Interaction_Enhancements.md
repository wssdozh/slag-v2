# 13. AI Assistant Interaction Enhancements

## Обзор
Спецификация архитектурных улучшений и интерактивных инструментов ИИ-ассистента SLAG v2 для устранения багов форматирования, поддержки сложных сценариев переноса задач, дополнения заметок и отката действий (Undo).

## Ключевые возможности

### 1. Выборочный пакетный перенос (Batch Selection Checkboxes)
- В карточке пакетного переноса `batch_reschedule` каждая задача снабжена нативным чекбоксом.
- По умолчанию выбраны все задачи (`checked: true`).
- Пользователь может исключить любую задачу из переноса кликом по чекбоксу.
- Счетчик на кнопке действия динамически пересчитывается: `Применить перенос (N)`. При снятии всех чекбоксов кнопка блокируется.

### 2. Составные условия переноса (Composite Split Scheduling)
- Поддержка разбора составных запросов в естественном языке:
  - `«1. задачу перенести на завтра, остальные две на послезавтра»`
  - `«чай на пятницу, остальное на понедельник»`
- Система извлекает целевые списки и формирует единый `batch_reschedule` с индивидуальными датами для каждой задачи.

### 3. Дополнение существующих заметок (`append_to_note`)
- Инструмент и действие `append_to_note(targetItemId, title, content)`.
- Интерактивная карточка в чате:
  - Заголовок: `Дополнение заметки: [[Название]]`
  - Визуальный блок добавленного текста с префиксом `+ `
  - Кнопки `[Дописать в заметку]` и `[Отклонить]`.
- Содержимое дописывается в существующую заметку в `.md` без перезаписи основного тела.

### 4. Откат действий (Undo Buffer & Revert)
- В `AppContext` ведется кольцевой стек снимков `actionHistory` (до 20 последних операций).
- При применении мутаций (перенос, дополнение заметки, смена статуса) всплывающий Toast содержит кликабельную кнопку `[Отменить]`.
- Доступна текстовая команда ассистенту: `«отмени последнее действие»` / `«верни как было»` через инструмент `undo_last_action`.

### 5. Управление фильтрацией ленты из чата (`filter_feed`)
- Инструмент `filter_feed(itemIds, queryLabel)` вызывает встроенный `applyAiFilter`.
- По запросу `«а с фильтром»` или `«отфильтруй ленту»` активируется ИИ-фильтр в `FeedHeader`.

### 6. Изоляция системного формата (Форматная безопасность)
- Служебные метаданные действий в истории диалога сериализуются в естественном виде без псевдо-протокольных скобок `[Действие ассистента: ... | Параметры: ...]`, исключая имитацию этого синтаксиса моделью.
- Защитный парсер в `extractActionBlock` перехватывает случайные утечки и преобразует их в валидные карточки интерфейса.

### 7. Архитектурное разделение слоев в UI и стандарт Slopotron
- **Разделение сущностей**: пузырь текстового сообщения ассистента и интерактивная карточка действия (`SuggestedAction`) отделены друг от друга. Карточка располагается независимым блоком под сообщением (аналогично карточке результатов поиска `Найдено N в хранилище`).
- **Слопотрон (/slopotron)**: исключение дублирования списков задач в тексте сообщений и канцелярских клише («Подтвердите действие в интерактивной карточке»). Ответ формулируется кратко и по-человечески.
- **Глубокий монохром (Linear Minimal Dark)**: удалены разноцветные рамки и градиенты. Все карточки выполнены в нейтральной палитре `#141416` с границами `border-white/[0.08]`. Цвет сохранен исключительно на бейджах приоритетов задач (`HIGH`, `MEDIUM`, `LOW`).
