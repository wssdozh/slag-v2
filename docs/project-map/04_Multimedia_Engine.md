## 1. Голосовые сообщения (Audio Waveform Engine)

Ввод мыслей голосом — важнейший элемент концепции «монолога в Telegram»:

- **Запись**: Web API `MediaRecorder` с аудио-кодеком `audio/webm;codecs=opus`.
- **Живая аудиоволна**: компонент `AudioRecorder` визуализирует частотную амплитуду входящего сигнала с микрофона через `AudioContext` и `AnalyserNode` в реальном времени.
- **Встроенный аудиоплеер (`AudioPlayer`)**:
  - Кнопка Play / Pause.
  - Кликабельный таймлайн воспроизведения с отображением текущей позиции и общей длительности (`MM:SS`).
  - Переключатель скорости воспроизведения: циклический клик `1.0x` → `1.5x` → `2.0x`.
- **Хранение**: файл сохраняется в `.attachments/voice_<timestamp>.webm`.

## 2. Видеосообщения («Квадратики» 1:1)

Вместо Telegram-кружков в SLAG v2 используются **видео-квадратики** с соотношением сторон 1:1 со скруглениями углов `rounded-xl` (12px), органично вписывающиеся в эстетику интерфейса Linear:

- **Видоискатель**: запись с веб-камеры или фронтальной камеры устройства в квадратном контейнере с маской.
- **Ограничения и оптимизация**:
  - **Жесткий лимит длительности: 60 секунд**.
  - Наглядный таймер обратного отсчета с автоматической остановкой по истечении минуты.
  - Разрешение 720×720 при битрейте до 2 Мбит/с (кодек `video/webm;codecs=vp9,opus`), что предотвращает неконтролируемое разрастание локального диска.
- **Интерактивный плеер (`VideoCirclePlayer`)**:
  - Воспроизведение прямо в теле карточки стрима.
  - Кнопка зацикливания, полноэкранный просмотр и скачивание.
- **Хранение**: `.attachments/video_<timestamp>.webm`.

## 3. Полноэкранная галерея (Image Lightbox Gallery)

При клике на любое изображение в ленте или инфо-панели открывается дистракшн-фри оверлей галереи:

- **Фон**: глубокий темный экран `bg-black/95 backdrop-blur-xl`.
- **Верхний тулбар**:
  - Название исходного файла.
  - Моноширинный счетчик позиции: `X из Y` (например: `2 из 8`).
  - Кнопки управления: `Зум +` (ZoomIn), `Зум -` (ZoomOut), `Сброс` (RotateCcw), `Закрыть` (X).
- **Навигация**:
  - Клавиши `←` (Влево) и `→` (Вправо) позволяют **листать все картинки активной папки**.
  - Боковые стрелки `ChevronLeft` и `ChevronRight`.
- **Масштабирование и панорамирование**:
  - Зум колесиком мыши (от 0.5x до 3x с шагом 0.25).
  - При масштабе > 1x зажатие ЛКМ позволяет свободно перемещать изображение.
- **Закрытие**: по клавише `Escape` или клику по фону (с соблюдением LIFO-стека).

## 4. Обработка разрешений и ошибок

- При блокировке доступа к микрофону или камере система перехватывает ошибку `NotAllowedError` и выводит деликатный тост в стиле Linear:
  *«Предоставьте доступ к микрофону/камере в настройках системы»*.
- Приложение никогда не падает при отсутствии мультимедийных устройств.
