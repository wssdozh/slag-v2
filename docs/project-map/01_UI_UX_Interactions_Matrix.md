## 1. Фундаментальные принципы визуального языка

Дизайн SLAG v2 базируется на эстетике **Linear & Vercel** и физике **Apple Fluid Motion**. Главная цель — исключить усталость глаз при непрерывной работе и обеспечить максимальную скорость ввода информации.

### 1.1. Цветовая палитра: глубокий темный монохром

| Токен | Значение | Роль в интерфейсе |
|---|---|---|
| `--bg-canvas` | `#08090a` / `#09090b` | Фоновый холст приложения и стрим-ленты |
| `--bg-sidebar` | `#0c0c0e` | Фон левого сайдбара и правой инфо-панели |
| `--bg-surface-1` | `#121215` / `#141417` | Фоновая подложка карточек заметок и композера |
| `--bg-surface-2` | `#16161a` / `#18181c` | Состояние hover для карточек, полей ввода |
| `--bg-surface-elevated`| `#1c1c21` / `#121215/95` | Модальные окна, контекстные меню с `backdrop-blur-xl` |
| `--border-hairline` | `rgba(255, 255, 255, 0.05)`| Ультра-тонкие границы карточек и разделители (1px) |
| `--border-hover` | `rgba(255, 255, 255, 0.12)`| Мягкое усиление границы при наведении курсора |

| `--accent-article` | `#60a5fa` (Blue-400) | Текстовый моноширинный акцент для статей |

### 1.2. Жесткие табу и запреты дизайна
1. **Категорический запрет на разноцветные градиенты и кислотные плашки**:
   - Никаких фиолетово-розовых радужных градиентов или цветных рамок.
2. **Правило «Никаких чипсов на чипсе» (No Chips on Chips)**:
   - Если карточка уже имеет фоновую заливку (`bg-[#141417]`), запрещено размещать внутри нее другие цветные плашки (badges/chips).
   - Тип записи («Таска», «Статья») отображается **чистым моноширинным текстом**:
     - `ПРАВИЛЬНО:` `<span class="text-[11px] font-mono text-amber-400/90 font-medium">Таска</span>`
     - `ЗАПРЕЩЕНО:` `<span class="bg-amber-500/20 px-2 py-0.5 rounded-full text-amber-300">Таска</span>`
3. **Запрет на боковые бордеры со скруглениями (Изогнутые скобки `(`)**:
   - В CSS сочетание `border-l-*` и `rounded-*` загибает границу по дуге, создавая эффект скобки.
   - Для цитат и ответов (`replyToId`) используется **замкнутый равномерный 1px контур**: `border border-white/[0.06] rounded-lg` и фон `bg-white/[0.03]`.
   - Если требуется вертикальная полоса, она верстается строго отдельным прямоугольным элементом `<div className="w-0.5 self-stretch bg-zinc-600 rounded-none shrink-0" />`.
4. **Никаких рамок фокуса (No Focus Rings)**:
   - Для всех `input`, `textarea` и `button` действует `outline: none; ring: 0`. Интерактивность подчеркивается только мягким изменением прозрачности границы (`border-white/[0.12]`).

### 1.3. Типографика
- **Основной шрифт (UI & Text)**: `Inter` / системный гротеск (13px для ленты, 14px для редактора, 12px для панелей).
- **Моноширинный шрифт (Meta, Tags, Code)**: `JetBrains Mono` / `SF Mono` (`10px` – `11px` для дат, счетчиков подзадач, тегов и бейджей шорткатов).

## 2. Физика интерфейса и Layered LIFO Stack

### 2.1. Мгновенный отклик (Apple Zero-Latency)
- Реакция на клики и переключения инициируется по событию `pointerdown`, а не по запаздывающему `click`.
- При нажатии активные элементы слегка сжимаются (`active:scale-[0.98]` с пружинным возвратом).
- Пружины анимаций имеют критическое затухание `damping: 1.0` (без визуального дребезга).

### 2.2. Послойный стек закрытия (LIFO Dismissal Stack)
Все перекрывающие слои регистрируются в едином стеке. Нажатие клавиши `Escape` или клик мимо закрывает **строго верхний слой**, не трогая нижние:

```
[Уровень 1] Полноэкранный редактор (Focus Editor) / Модалка настроек
  └── [Уровень 2] Модальное окно (Поиск ⌘K / Папка / Триаж)
        └── [Уровень 3] Единое контекстное меню / Подменю
              └── [Уровень 4] Полноэкранный Image Lightbox Gallery
```

- Если открыт Lightbox поверх модалки — `Escape` закрывает *только Lightbox*.
- Если открыто контекстное меню поверх Focus Editor — клик мимо закрывает *только контекстное меню*.

## 3. Исчерпывающая матрица интеракций: ЛКМ vs ПКМ

| Зона / Компонент UI | Левый клик (ЛКМ / Tap) | Правый клик (ПКМ / Long-press) |
|---|---|---|
| **Карточка заметки (Note Card)** | Фокус карточки. Клик по фото — открывает Lightbox. Клик по аудио/видео — воспроизведение. Клик по `#тегу` — фильтрация ленты. | Открытие **Единого контекстного меню заметки** (Ответить, Фокус-редактор, Закрепить, Сменить тип, Переместить в папку, [[Линк]], Копировать Markdown, В корзину `.trash/`). |
| **Карточка задачи (Task Card)** | Клик по круглому чекбоксу — мгновенное переключение `Todo` ↔ `Done`. Клик по чекбоксу подзадачи — переключение подзадачи без модалок. Клик по «Подзадачи N из M» — сворачивание/разворачивание. | Открытие **Единого контекстного меню** (изменение дедлайна, приоритета, перемещение, удаление в `.trash/`). |
| **Карточка статьи (Article Card)** | Клик по кнопке «Читать полностью ↓» — раскрытие инлайн-аккордеона в ленте. Клик по заголовку или иконке `Maximize2` — открытие в **Focus Editor**. | Открытие **Единого контекстного меню** (редактирование, смена папки, экспорт Markdown). |
| **Кнопка «Три точки» на карточке** | Открывает **то же самое единое контекстное меню**, что и ПКМ (устранено дублирование). | Дублирует вызов меню. |
| **Плашка ответа (Reply Banner)** | Плавный скролл к родительской записи с кратковременной подсветкой (`item-highlight-pulse`). Клик по крестику `X` — отмена ответа. | Скопировать ссылку на родительскую заметку `[[...]]`. |
| **Вики-ссылка `[[Заметка]]`** | Плавный переход и скролл к целевой записи (с автоматическим переключением активной папки, если нужно). | Открыть целевую запись в фокус-редакторе. |
| **Папка в дереве сайдбара** | Одиночный клик — выбор активной папки (лента мгновенно фильтруется, инфо-панель обновляется). Клик по стрелке `>` — сворачивание/разворачивание подпапок. | Открытие **Контекстного меню папки** (Создать подпапку, Настроить иконку и описание для ИИ, Запустить ИИ-триаж для папки, Переименовать, Удалить в корзину). |
| **Иконка/имя папки (Дабл-клик)** | Быстрый переход в режим инлайн-переименования папки. | — |
| **Пустое пространство стрима** | Снятие выделения, закрытие контекстных меню, фокус курсора в поле ввода композера. | Вызов **Контекстного меню ленты** (Новая заметка, Новая таска, Новая статья, Поиск [⌘K], Переключить режим Inbox). |
| **Поле ввода композера** | Установка фокуса для набора текста. Ввод `Enter` — отправка в стрим. `Shift+Enter` — перенос строки. | Системное контекстное меню (Вставить / Копировать / Проверка орфографии). |
| **Кнопка типа в композере** | Открытие выпадающего списка: Заметка / Таска / Статья. | Быстрый циклический перебор (Заметка → Таска → Статья). |
| **Кнопка микрофона** | Старт / остановка записи голосового сообщения с живой аудиоволной. | Отмена записи без сохранения. |
| **Кнопка видеокамеры** | Открытие видоискателя для записи квадратного видео 1:1 (лимит 60с). | Отмена записи видео. |
| **Кнопка `Maximize2`** | Перенос набранного в композере текста в Focus Editor. | — |
| **Кнопка `+Ai` в композере** | Запуск тихого Gemini Flash анализа для подбора тегов из словаря. | Принудительная полная переиндексация таксономии тегов. |
| **Картинка в ленте / инфо-панели** | Открытие полноэкранной галереи Image Lightbox. | Контекстное меню картинки (Сохранить на диск, Копировать изображение, Удалить). |
| **Изображение в Lightbox** | Клик по фону — закрытие. Стрелки — листание `←` / `→`. Зажатие ЛКМ при зуме — панорамирование. | Контекстное меню изображения (исходный масштаб, копировать путь). |
| **Сплиттеры изменения ширины** | Зажатие ЛКМ и drag — масштабирование панелей с сохранением в localStorage. | Двойной клик ЛКМ — сброс ширины к эталонным значениям (260px / 320px). |
| **Описание папки в инфо-панели** | Клик по тексту — переход в режим инлайн-редактирования контекста для ИИ. | Сгенерировать авто-описание папки через ИИ на основе анализа заметок внутри нее. |
| **Шапка папки: селектор представлений [Лента / Канбан / Календарь]** | ЛКМ — переключение активного представления контента папки (`feed`, `kanban`, `calendar`). | Хоткеи быстрого переключения видов (`⌘1` — Лента, `⌘2` — Канбан, `⌘3` — Календарь). |
| **Канбан: Карточка задачи в столбце** | Клик по чекбоксу — изменение статуса задачи. Клик по тексту — открытие карточки/редактора. Drag & Drop — перенос задачи между кастомными столбцами с автообновлением `kanbanColumn` и `statusMapping`. | Контекстное меню задачи (дедлайн, приоритет, перенос в папку, корзина). |
| **Канбан: Колонка «Материалы» (ТРИЗ-док)** | Клик по карточке заметки/статьи — открытие в фокус-редакторе. Drag & Drop в колонку задач — фазовый переход (конвертация в задачу или создание связанной таски). Тумблер `[📚]` в шапке — скрытие/показ колонки. | Меню управления материалами папки. |
| **Канбан: Заголовок кастомного столбца** | Клик по названию — инлайн-переименование столбца. Drag & Drop за заголовок — изменение порядка колонок. Кнопка `+` в столбце — быстрое создание задачи в этой стадии. | Меню столбца: изменить `statusMapping`, очистить столбец, удалить столбец с переносом карточек. |
| **Канбан: Кнопка «+ Столбец»** | Добавление нового кастомного этапа в жизненный цикл папки с выбором имени и семантического маппинга. | — |
| **Календарь: Ячейка дня** | Клик по дате — создание задачи с автоматически назначенным `dueDate`. Клик по карточке — открытие Focus Editor. Drag & Drop задачи на день — назначение/перенос дедлайна. | Контекстное меню дня: «Создать задачу на этот день». |
| **Календарь: Панель «Без дедлайна»** | Клик по стрелке — раскрытие/сворачивание шторки. Drag & Drop задачи из панели на ячейку календаря — моментальное планирование дедлайна. | — |
| **Правый сайдбар: переключатель [Инфо / Ассистент]** | ЛКМ — переключение правой панели между метаданными/медиа папки и ИИ-Копилотом. Доступен параллельно с любым из трех центральных представлений. | Хоткей переключения `⌘J` / `Ctrl+J`. |
