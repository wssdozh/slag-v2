## 1. Концепция локального поиска

Для системы заметок скорость поиска критична. В SLAG v2 поиск реализован на базе легковесного in-memory поискового движка **`@orama/orama`**:

- **100% Local & Offline**: индекс хранится в оперативной памяти устройства и не требует отправки данных на сторонние серверы.
- **Нулевая задержка**: среднее время поиска по 10 000+ заметкам составляет менее 5 миллисекунд.
- **Алгоритм BM25**: математически выверенное ранжирование релевантности с учетом частоты терминов.
- **Fuzzy Tolerance**: устойчивость к опечаткам (толерантность 1 символ).

---

## 2. Схема индексации Orama

Каждая заметка индексируется по следующей схеме:

```typescript
import { create, insert, search } from '@orama/orama';

export const slagSearchSchema = {
  id: 'string',
  type: 'string',     // 'note' | 'article' | 'task'
  title: 'string',
  content: 'string',
  folder: 'string',
  tags: 'string[]',
  createdAt: 'number'
} as const;
```

При любом изменении, создании или удалении заметки поисковый индекс мгновенно и инкрементально обновляется без перестроения всего хранилища.

## 3. Командная панель поиска (Command Palette `⌘K`)

- **Глобальный шорткат**: `⌘K` (macOS) или `Ctrl+K` (Windows/Linux) открывает модальное окно поиска из любого места программы.
- **Интерфейс**:
  - Строка ввода с автофокусом и иконкой лупы.
  - Быстрые фильтры типов в один клик: `Все`, `Заметки`, `Таски`, `Статьи`.
  - Список результатов с подсветкой совпадений, указанием папки и тегов.
- **Навигация с клавиатуры**:
  - `↑` и `↓` — выбор нужного результата в списке.
  - `Enter` — мгновенный переход к выбранной заметке (плавный скролл в ленте и подсветка карточки).
  - `Escape` — закрытие командной строки (верхний слой стека LIFO).
