# Свойства задач, заметок и статей: что проверяет синхронизация

Матрица на основе [типов](../src/types/index.ts#L2-L76), а не списка полей, видимых в одном редакторе. [Автотест](../scripts/note-field-matrix.test.mjs) сверяет по AST все 28 полей `SlagItem`, 14 полей `SlagAttachment`, 4 поля правила повтора и 3 поля подзадачи. Добавление или удаление поля без обновления матрицы ломает тест.

| Поля | Кто пишет | Что проверяется |
|---|---|---|
| `title`, `content`, `tags`, `folder` | Композер, полноэкранный редактор, перемещение, ИИ, MCP в обычном хранилище; Markdown | Проекция и зашифрованная запись каждого типа, внешняя правка, два порядка независимых правок, одинаковые и конкурирующие правки. Теги сливаются по членству; тело — построчно только там, где это однозначно. Перенос папки не выбирается отдельным свойством при разборе. |
| `isPinned`, `isArchived` | Закрепление в ленте/меню; архив — ИИ/Markdown (команда архивирования убрана из меню) | Set/clear для всех типов. `false` и отсутствие равнозначны. |
| `replyToId`, `linkedItemIds` | Ответ из карточки/композера; явный список связанных ID — сохранение модели, импорт и YAML, не то же самое, что `[[ссылка]]` в тексте | Запись, замена и очистка, независимые правки. Ключи YAML `replyTo`, `linked`. |
| `customProps` | Патч ИИ и YAML (`customProps`), импорт | `false`, `null`, вложенные значения, очистка; независимые ключи верхнего уровня могут слиться. Наличие произвольного YAML-ключа вне `customProps` не является поддерживаемым способом записи этого поля. |
| `status`, `priority`, `kanbanColumn` | Лента, редактор, ИИ, MCP; канбан меняет **статус**, отдельный `kanbanColumn` доступен через ИИ и YAML, не является источником позиции карточки | Изменение/сброс, статусы и приоритеты по умолчанию, слияние с независимым полем. |
| `dueDate`, `reminder`, `duration`, `recurrence` | Композер/редактор, календарь, rollover, MCP, YAML; отдельные поля в патче ИИ | Установка, изменение, снятие и проекция. Все поля правила `freq`, `interval`, `weekdays`, `resetSubtasks`; эквивалентность пропущенных `interval: 1` / `resetSubtasks: true`, но не `false`. Несовместимое сочетание срока, напоминания и серии нельзя молча смешивать. |
| `streak`, `history`, `lastCompletedDate`, `subtasks` | Завершение/возобновление, rollover, редактор и чекбоксы, MCP/YAML | Запись, очистка, независимые и конкурирующие правки. У старого YAML-списка есть `id`, `title`, `completed`; у Markdown-чекбокса ID — позиция при разборе, не постоянный внешний адрес. Текст не должен уничтожать отдельный список при выборе полей. |
| `readingTimeMinutes`, `summary` | Редактор/создание вычисляет время; Markdown (`readingTime`, `summary`) и модель позволяют сохранить явное значение. Отдельного ручного редактора аннотации статьи нет; `summary` медиа — другое поле. | Явные значения и очистка, вычисленное время при пропуске, независимая правка текста/явного времени, сохранение и снятие аннотации в реальном сценарии доставки. |
| `type` | Композер, редактор, меню, канбан, ИИ, MCP, Markdown | 6 направлений. Общие поля остаются, поля прежнего типа не продолжают жить только на части устройств. Не объединять с параллельной правкой поля прежнего типа. |
| `attachments` | Композер, редактор, удаление/переименование файла, фоновые транскрипция и отрисовка аудио, импорт/Markdown | `id`, `name`, `type`, `mimeType`, `size`, `relativePath`, `registryBlobId`, `duration`, `waveform`, `extractedText`, `summary`, `enrichmentStatus`, `enrichmentError`. Байты отдельно. `dataUrl` и состояния `processing`/`idle` локальные. Независимые метаданные можно слить только для **того же подтверждённого** blob и той же структуры списка; текст транскрипции, аннотация, результат и ошибка обогащения остаются связанной группой. Смена файла/имени/привязки или два разных результата обогащения не скрывают конфликт. |
| `id`, `filename`, `createdAt`, `updatedAt` | ID назначается при создании и связывает имя, корзину и реестр; имя файла локальное, время задаёт хранилище | ID и даты сохраняются, но изменение метки времени само по себе не является пользовательской правкой; имя файла исключено из синка. Смещение ID не переименовывает запись в реестре. |

## Границы записи

- В приложении общий [writer](../src/context/hooks/useItemWrites.ts) идёт в [хранилище](../src/lib/storage/index.ts#L893-L970). Массовый rollover пользуется `saveItems`; приём реестра и legacy-импорт не должны публиковаться назад как местные действия. Редактор передаёт исходный снимок, а не угадывает его по времени. Внешнее изменение при работающем приложении проходит через watcher и `recordExternal`.
- При закрытом приложении [реплика](../src/lib/sync/notes/replica.ts#L394-L432) берёт все различия проекции для единственного файла с совпадающими ID, папкой и маркером подтверждённой ревизии. Старый маркер покрывает тело, а не YAML: файл, стоящий впереди сохранённого журнала, не публикуется как пользовательская правка. Для немаркированных копий прежний узкий захват текста остаётся; переносы между физическими папками, удаление «по отсутствию файла» и YAML с неизвестной базой **не** разрешены автоматически этим механизмом. Результат со старой базой не обходит проверку непрерывности и lifecycle.
- В [MCP](../src/mcp/vault.ts#L456-L528) и headless-режиме прямые изменения файлов специально разрешены в обычном vault и блокируются в подключённом реестре. Это не альтернативный транспорт через релей. Тесты подтверждают защиту при появлении маркера, чтение и патчи; API не предоставляет все поля модели и не должен притворяться, что предоставляет.

## Уровни проверки

- Полевая матрица: обход всех типов, проекция YAML → Markdown → модель, `editFromDisk`, реальное шифрование/расшифровка и слияние, выбор отдельного свойства. Типовые данные — не все значения и не полный декартов набор пар полей.
- [Регрессии реплики](../scripts/note-replica.test.mjs#L89-L183): холодное чтение, внешние метаданные, файл впереди журнала, отдельные сценарии разрыва lifecycle/пропущенной истории. [Стенд настоящего релея](../scripts/note-live-smoke.mjs): три клиента, один offline, JSON-перезапуск очереди, конкурентные заголовки и очистка свойств трёх типов, повторное чтение и ни одной новой альтернативы в этом сценарии. Несовместимые правки в остальных сценариях всё ещё дают альтернативы.
- Playwright: лента, редактор, канбан, длительность в календаре, ассистент, повтор, изменение YAML и разборы. Результат 27/30; три падения повторяются без этого диффа на `4b17e11a`: [позиция подменю](../e2e/context_menu_flyout.spec.ts#L68-L70), [закрытие диалога Escape](../e2e/slag/editor.spec.ts#L563-L565), [перенос из временного слота в «Весь день»](../e2e/slag/editor.spec.ts#L661-L663). Они не засчитаны как пройденные. Прогон браузера не равен проверке реальных Tauri WebView, напоминаний на устройствах или связки календаря Android с разными часовыми поясами.
- Не проверяли заново на установленных Windows/Linux/Android: нет выкладки. Не заявляем матрицу системных уведомлений, всех медиаформатов, всех составных гонок и внешних переноса/удаления в реестре. Автоматическое слияние разных правил повторения, разных структур вложений и потерянной базы не добавлено.
