# AGENTS.md — контракт верстки

Linear / Vercel dark. Токены объявлены в `src/styles/theme.css`; здесь то, что нельзя забыть.

## Токены

| класс | значение | где |
|---|---|---|
| `bg-canvas` | `#131316` | окно, лента, канбан, календарь |
| `bg-canvas-subtle` | `#0f0f12` | подложки, неактивные зоны |
| `bg-panel` | `#131316` | сайдбар, правая панель, шапки |
| `bg-surface` | `#1a1a1f` | карточки, редактор, композер |
| `hover:bg-surface-hover` | `#212127` | подсветка карточки или строки |
| `bg-surface-elevated` | `#24242c` | модалки, меню, поповеры (`backdrop-blur-xl`) |
| `border-subtle` | `rgba(255, 255, 255, 0.08)` | разделитель панели, контур карточки |
| `border-hover` | `rgba(255, 255, 255, 0.14)` | контур под курсором |
| `text-fg-primary` | `#f4f4f5` | заголовки, текст заметки |
| `text-fg-secondary` | `#a1a1aa` | подзадачи, описания папок |
| `text-fg-muted` | `#71717a` | даты, тайминги, теги |
| `text-fg-dim` | `#52525b` | плейсхолдеры, приглушенные иконки |

## Четыре запрета

1. Градиенты и кислотные плашки — нет.
2. Антиматрёшка: карточек внутри карточек и внутренних подвалов нет. Иерархия — типографикой и `gap-2`.
3. Чипсы на чипсе: тип записи — `text-[11px] font-mono text-zinc-400`, без цветной подложки.
4. Изогнутые бордеры: `border-l-*` рядом с `rounded-*` нет. Реплаи — `↳` или штрих `rounded-none`.

## Фокус и слои

- Инпуты, textarea, кнопки: `outline-none ring-0`. Интерактивность — мягкая граница.
- Радиусы: кнопка и инпут `rounded-md`, карточка `rounded-xl`, модалка и композер `rounded-2xl`.
- Шрифты: Inter 13/14px, JetBrains Mono 10–11px для дат, тегов, счетчиков.
- LIFO: редактор/настройки → диалог → контекстное меню → lightbox. `Escape` и клик мимо закрывают только верхний слой. Модалку поверх открытого меню не закрываем.

## Интеракции

- Горячие клавиши живут в `src/lib/commands.ts` (`APP_COMMANDS`), там же и проверяй перед правкой: `mod+f`/`mod+k` поиск, `mod+j` ассистент, `` mod+` `` логи, `c` таска, `n` заметка, `mod+,` настройки. Новое сочетание добавляется в каталог, а не отдельным `keydown`-слушателем в компоненте.
- Мобильное живёт в `src/components/Mobile/` и включается через `useIsMobile`. Безопасные зоны, клавиатура и вьюпорт — `useVisualViewport`. Нижние действия — `MobileActionSheet`, не самодельный `fixed`-див.
