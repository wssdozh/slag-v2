# AGENTS.md — код в src/

Действует на всё под `src/`. Верстку уточняет `src/components/AGENTS.md`.

## React 19

- Файл компонента экспортирует только компоненты, иначе ломается Fast Refresh. Константы и хелперы — в отдельный модуль.
- В `useEffect` нет синхронного `setState`: состояние ставится в обработчике или считается при рендере.
- Массив зависимостей полный, линтер не отключаем.
- Каждый `addEventListener` получает парный `removeEventListener`.
- Колбэки, уходящие в глубокие дети или глобальные слушатели, — в `useCallback`.

## TypeScript

- `any` нет. Вход снаружи — `unknown` и сужение.
- Доменные типы (`SlagItem`, `FolderMeta`, `VaultMeta`, `SlagAttachment`) — в `src/types/index.ts`, локальных копий нет.
- Имена от сущности к свойству: `activeItemId`, `currentFolder`. Булевы — `is`, `has`, `can`.
- `@tauri-apps/*` — только в `src/lib/*`, включая динамический `import()`. Компоненты и UI-хуки его не видят.

## Tailwind v4

- Порядок классов: позиционирование → flex/grid → размеры → типографика → цвета → состояния.
- Инлайн-стили только для вычисленной геометрии.

## Форма кода

- Новое перед написанием: `ls src/lib`, `ls src/hooks`, `grep` по имени функции. Если аналог есть — беру его, а не пишу рядом второй.
- Вынос по третьему повтору. Два похожих места терплю, третье выношу. Один потребитель — не повод для абстракции.
- Куда выносить: чистая функция → подходящий домен в `src/lib/` (`ai`, `storage`, `sync`, `vault`, `time`, `media`) или плоско, если модуль один; стейтфул-логика → `src/hooks/` (`gestures`, `layout` или плоско); повторяющийся визуал → модуль рядом с местом использования. Кит `src/components/UI/` живой — все 26 файлов импортируются, — но прежде чем тащить оттуда компонент или писать рядом второй, `grep` по импортам.
- Папка в `lib/` или `hooks/` появляется на третьем родственном модуле. Один файл — плоско. Barrel `index.ts` только у `storage` и `sync`.
- Длинный файл не переписываю целиком, но и не наращиваю. Правка в файле больше 500 строк (`FullscreenEditor`, `AdminPanel`, `CalendarView`, `Composer`, `SettingsModal`), где я добавляю больше ~50 строк: сначала выношу кусок, потом добавляю.
- Резать по швам, а не по строкам: несколько `useEffect` на разные зоны, 10+ пропсов, JSX глубже четырёх уровней, ветвление на 5+ веток в одном обработчике.
- Обёртка ради одной реализации и `interface` с одним исполнителем — тот же дубль, только замаскированный.
