# AGENTS.md — код в src/

Действует на всё под `src/`. Верстку уточняет `src/components/AGENTS.md`.

## React 19

- Файл компонента экспортирует только компоненты, иначе ломается Fast Refresh. Константы и хелперы — в отдельный модуль.
- В `useEffect` нет синхронного `setState`: состояние ставится в обработчике или считается при рендере.
- Массив зависимостей полный, линтер не отключаем.
- Каждый `addEventListener` получает парный `removeEventListener`.
- Колбэки, уходящие в глубокие дети или глобальные слушатели, — в `useCallback`.

## TypeScript

- `any` нет. Вход снаружи — `unknown` и сужение.
- Доменные типы (`SlagItem`, `FolderMeta`, `VaultMeta`, `SlagAttachment`) — в `src/types/index.ts`, локальных копий нет.
- Имена от сущности к свойству: `activeItemId`, `currentFolder`. Булевы — `is`, `has`, `can`.
- `@tauri-apps/*` — только в `src/lib/*`, включая динамический `import()`. Компоненты и UI-хуки его не видят.

## Tailwind v4

- Порядок классов: позиционирование → flex/grid → размеры → типографика → цвета → состояния.
- Инлайн-стили только для вычисленной геометрии.
